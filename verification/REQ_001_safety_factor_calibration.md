## 0. 結論

**安全率 0.7 は「決定」ではなく「未校正の初期値」である。**
`competition/baseline_slalom.py` の**全 5 コミットで既定値は 0.7 のまま一度も変わっておらず**、
文書が規定した探索手順（0.6 → 0.7 → 0.8）は**一度も実行されていない**。

**あわせて、文書と実装の不整合を 3 件見つけた**（§1-3）。**校正実験を設計する前に、
どの数値が正なのかを確定させる必要がある。**

## 2. ②校正実験の骨子

### 2-1. 目的

**「完走率 100% を維持できる最大の安全率」を、再現可能な記録つきで確定する**（§2.2 の教授裁定 ①）。
理由も §2.2 が書いている: **L0-c は「学習が勝つべき相手」であり、不必要に弱く作ると比較が不公平**。

### 2-2. 先に決めること（実験の前）

| # | 決めること | 私の推奨 |
|---|---|---|
| **A** | **§2.2 の表を 0.6 のままにするか 0.7 に直すか** | **表は「探索の出発点」と明記して残し、実装の既定は校正の結果で置き換える。**どちらの数値も「正」にしない — **校正前は未確定である**と書く |
| **B** | **どの帯で探索するか** | **探索は検証帯 `competition/mazes/validation/`**（v4・20 面）。**§2.2 の seed 4000-4019 は失効しているので使わない。**最終確認を評価帯で行うかは**教授の裁定事項**（評価帯の消費になる） |
| **C** | **刻みと範囲** | 0.6 / 0.7 / 0.8 の 3 点では粗い。**0.60 から 0.05 刻みで上げ、初めて完走率が 100% を割った 1 つ手前**を採る。$v$ は安全率に比例するので、0.05 刻みは $v_\max$ で 0.19 m/s 刻みに相当する |
| **D** | **🔴 何試行やるか（下記 2-3 が本題）** | **n=20（1 面 1 試行）では足りない** |

### 2-3. 🔴 統計の設計 — 「完走率 100%」は $n$ を書かないと意味を持たない

**20 面すべて完走しても、真の完走率について言えるのは「$\ge$ 86.1%」だけである**（片側 95%）。

| 試行数 | 全数完走が担保する真の完走率（片側 95% 下限） |
|---|---|
| **20** | **0.861** |
| 40 | 0.928 |
| 60 | 0.951 |
| 100 | 0.971 |

> **`AUDIT_015`（B1）で登録した型と同じである。**「100%」という表示は $n$ が小さいほど出やすい。
> **「完走率 100% を維持できる最大値」という判定規則は、$n$ を固定しないと安全率を上振れさせる**
> （$n$ が小さいほど大きな安全率が「100%」に見える）。
>
> **推奨**: **1 面あたり複数試行**（初期擾乱を変える）で $n\ge60$ を確保し、
> **判定を「完走率 100%」ではなく「片側 95% 下限 $\ge$ 0.95」**とする。
> **⚠️ クラスタ構造に注意**（`AUDIT_015` §3）: 同じ面の反復は独立でないので、
> **面を増やす方が試行を増やすより効く**。検証帯 20 面が上限なら、**その旨を限界として記録する**

### 2-4. 記録する量（§8 の表を埋める）

| 列 | 備考 |
|---|---|
| 安全率 | 0.60 から 0.05 刻み |
| **完走率**（＋ **$n$** と **片側 95% 下限**） | $n$ を必ず併記（2-3） |
| 最速タイム中央値 | M5 の基準値に直結（§3） |
| 横偏差 最大 / RMS | §2 の教授裁定②の条件。**曲率不連続が原因で安全率を上げられない場合はクロソイドへ進む**という分岐がここに紐づく |
| 採否と理由 | 落ちた面の**面 ID と失敗様式**（衝突／時間切れ／スタック）まで |

### 2-5. 反証条件（先に登録する）

| # | 観測されたら |
|---|---|
| **F-1** | **安全率を上げても完走率が落ちない**（0.9 でも 100%）→ **物理限界の実測値そのものを疑う**（$v_\max$=3.86 等が保守側に外れている可能性） |
| **F-2** | **0.6 でも完走率が 100% にならない** → 安全率以外に律速がある（経路生成・追従制御）。**安全率の校正では解けない** |
| **F-3** | **横偏差が安全率に対して単調でない** → 追従制御が非線形に効いている。**円弧接続の曲率不連続（§2 注）が疑わしい** |
| **F-4** | **失敗が特定の面に集中する** → 完走率という 1 つの数で扱うのは不適切。**面の性質（最小 $R$・連続ターン数）で層別**する |

## 3. ③M5 再導出条項との接続

### 3-1. 依存の連鎖

$$\text{安全率}\ \longrightarrow\ v_\max,a_\max,a_{lat}\ \longrightarrow\
\text{L0-c の最速タイム}\ \longrightarrow\ \textbf{M5 の基準値}$$

**L0-c は「学習が超えるべき古典ベースライン」なので、その速さが M5 の合格線を決める。**
**安全率が動けば合格線も動く。**

| 校正の結果 | L0-c | M5 の gate |
|---|---|---|
| **0.7 → 0.8**（上げられた） | **速くなる** | **上がる**（学習に厳しくなる） |
| **0.7 → 0.6**（下げが必要だった） | **遅くなる** | **下がる**（学習に甘くなる） |

> **どちらに転んでも M5 の基準値は再導出が要る。**
> **「校正しても M5 は変わらない」という結末は存在しない**（安全率が 0.7 のままと確定した場合を除く）。

### 3-2. 条項の案（`RESEARCH_PLAN` へ入れるなら）

> **L0 ベースラインの物理パラメータ（安全率・速度上限・加速度上限）を変更したときは、
> M4/M5 の基準値を再導出し、変更前後の値を併記して記録する。
> 基準値の出所となった L0 の版（コミットと安全率）を、基準値と同じ場所に書く。**

**根拠**: `AUDIT_008`（M4/M5 gate の検定）で私が指摘した**生存者構造・凍結表**の問題と同じ型である。
**「基準値がどの版から出たか」が書かれていないと、版が動いたときに基準値が腐る**
（`AUDIT_011` §5-quater の「合成値は腐る」の一般形）。

### 3-3. ⚠️ 現行の M5 基準値の扱い

**現行の M5 基準値は 0.7 の上に乗っており、その 0.7 に記録が無い。**
したがって **M5 の基準値は現時点で「出所不明の値に依存した値」である。**

- **本校正が終わるまで、M5 の基準値を「確定」と書かないこと**を推奨する
- 既に確定として書かれている箇所があれば、**§8 と同じ注記（未校正パラメータに依存）**を添える
- **`EVAL_NARRATIVE.md` §10 で私が指摘した「L0-c の 16.83 s を無条件の成功値として提示した」誤り**は、
  **同じ根の別の症状**である（帯が変わって無効になったが、**安全率が変われば同じことが起きる**）
