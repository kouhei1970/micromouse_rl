## 2.【R38-4】指摘 1（要注記）: §2 の mtime 表は「10 点目の時刻」ではない

判定文書 §2 は**発火認定の機械記録**として mtime を挙げるが、`AUDIT_026` の復元と突き合わせると
**6 本中 4 本は 10 点目より後の評価点の mtime** である:

| seed | 判定文書の mtime | **10 点目の実時刻**（monitor / TB） | |
|---|---|---|---|
| 1 | 14:49:49 | **14:46:28 / 14:46:28** | ← 11 点目以降 |
| 2 | 14:52:22 | 14:52:22 / 14:52:24 | ✅ |
| 3 | 14:49:16 | 14:49:16 / 14:49:18 | ✅ |
| 4 | 14:52:04 | 14:52:06 / 14:52:06 | ✅ |
| 5 | 14:52:24 | **14:45:49 / 14:48:17** | ← 11 点目 |
| 6 | 14:51:41 | **14:40:23 / 14:41:28** | ← 11 点目以降 |

**表そのものは「各ファイルの mtime」として正確**だが、**発火時点の証拠としては使えない。**
**規約 §9-16 に本日足した「上書きされる証拠」の細目が、当日の判定文書自身に現れた形**である。

**是正案**: §2 に 1 行 —

10 点目の時刻は `AUDIT_026` の追記型 2 経路（monitor の `t_start` / TB の `wall_time`）による復元を参照。**」

**判定は覆らない**（10 点すべてが 0.00 で、時刻に依存しない）。

## 3.【R38-5】要記載 2 件 — **100 万歩以降が P1 の判定に入っている**

### 指摘 2（要記載）: **P1 の測定時点は事前登録されていない**

- **打ち切り条文の判定**は 100 万歩までの 10 点だけを使っており、**分離は正しい**（§3 の見出しで明示）
- **しかし P1 の判定は「最終の定期評価」＝ 100 万歩以降の点を使っている**
- **カードの P1 は「6 seed の `goal_rate` 中央値 < 0.10」だけで、測定時点を指定していない**

**🟢 ただし結論は不変である。**候補となるどの時点でも中央値は 0.0000:

| 測定時点 | 6 seed の `goal_rate` | 中央値 |
|---|---|---|
| **1,000,000 歩**（打ち切り窓の終端） | 0, 0, 0, 0, 0, 0 | **0.0000** |
| **2,000,000 歩** | 0, 0, **0.05**, 0, 0, 0 | **0.0000** |
| **2,000,896 歩**（最終） | 0, 0, 0, 0, 0, 0 | **0.0000** |

**是正案**: §1-1 に「**測定時点は事前登録されていないが、1,000,000 / 2,000,000 / 2,000,896 歩の
いずれで測っても中央値は 0.0000 であり、判定は測定時点の選び方に依存しない**」を記載する。
**これを書かないと、「結果を見てから時点を選んだ」という疑いが構造的に立つ。**

### 指摘 3（要是正）: **「200 万歩」が 2 つの別の点を指している**

| 箇所 | 記述 | 実際の点 | 値 |
|---|---|---|---|
| §1-1 | 「**最終の定期評価（200 万歩**・検証帯 20 面 × 1 試行）」 | **2,000,896 歩** | 0.000 |
| §3 | 「**seed3 が 200 万歩**…で `goal_rate` 0.05 を記録した」 | **2,000,000 歩** | **0.05** |

**同じ「200 万歩」という語が別の評価点を指しており、しかも値が 0.000 と 0.05 で食い違って見える。**
**読者は文書が自己矛盾していると読む経路がある。**

（実データ: seed3 = 1,900,000→0.0 / **2,000,000→0.05** / 2,000,896→0.0。
seed4 = **1,900,000→0.05** / 2,000,000→0.0 / 2,000,896→0.0。）

**是正案**: **歩数を桁まで書く**（「2,000,896 歩（最終評価）」「2,000,000 歩」）。
