## 1. 校正試験（既知解・非循環）

障害物の無い自由空間に点源を置き、**厳密なユークリッド距離との比**を方位の関数として測った。
**答えが解析的に分かっているので、両解法の異方性を循環せずに測れる。**

| 方位 | 8 近傍 / 厳密 | FMM / 厳密 |
|---|---|---|
| 0° | **1.00000** | **1.00000** |
| 10° | 1.05689 | 1.00363 |
| 20° | 1.08124 | 1.00758 |
| **23°** | **1.08235**（最大） | 1.00889 |
| 30° | 1.07390 | 1.01075 |
| 45° | **1.00000** | **1.01287**（最大） |

- **8 近傍**: 理論値 $\sqrt{4-2\sqrt2}$ = 1.08239（22.5°）に対し実測 1.08235（23°。格子上の量子化）。
  **0° と 45° では厳密に 1.000**（この 2 方位は 8 近傍で厳密に表現できる）
- **FMM**: 最大偏差 **+1.287%**、**45° で最大**。**上に外す向き**である

> **🔴 ここが本測定の要点**: **2 つの解法は誤差が最大になる方位が違う。**
> **8 近傍は 22.5° で最大・0°/45° で 0、FMM は 45° で最大・0° で 0。**
> **したがって「8 近傍 − FMM」は 8 近傍の誤差そのものではなく、2 つの誤差の差である。**

## 3. F-3 が外れた理由 — **私の理由づけの中に反証が入っていた**

**登録した理由**: 「迷路の測地線は直線区間が軸方向（0°）、角切りが概ね 45° に寄る。
**どちらも 8 近傍の誤差が 0 になる方位**である。したがって方位一様平均 5.5% より小さくなる。」

**この理由づけは正しく、実測（+2.2%）も 5.5% よりはっきり小さい。支持された。**

**しかし同じ理由から、次が従う** — **45° は FMM の誤差が最大になる方位である。**
**そこでは 8 近傍が厳密（誤差 0）で FMM が +1.29% 外すので、差の符号は逆転する。**
**seed 7000 の −0.21% はこれである。**

> **私は「8 近傍の誤差が 0 になる方位」までは書いたのに、
> 「その方位で相手はどうなるか」を書かなかった。**
> **比較の対象が両方とも誤差を持つとき、片方の誤差だけを論じると符号を外す。**
> **これは `AUDIT_011` §6 で自分に課したはずの作法（「概算には、そのモデルが原理的に
> 出せない領域を添える」）の、対象が 2 つある版である。**

**教訓（作法 15 として登録）**: **2 つの近似を比べるときは、両方の誤差曲線を先に描く。**
**「A の誤差が 0 になる場所」は「A と B の差が 0 になる場所」ではない。**

## 4. R37 の条文に載せる値（教授への提案）

**実測をそのまま「8 近傍の誤差」と書いてはならない**（§1 の理由）。条文には次の形を推す。

> **条件 C の場は「配置空間上の 8 近傍格子測地」と定義する。**
> 真のユークリッド測地に対する**上界は +8.24%**（$=\sqrt{4-2\sqrt2}$、方位 22.5° で最大。
> 0° と 45° では厳密）、方位が一様分布する場合の平均は約 +5.5%。
> **本迷路系での実測**: 1 次精度 FMM（自身の異方性は最大 +1.29%・45° で最大）との差は
> **中央値 +2.2%（5 面で −0.2〜+2.8%）**。**上界よりはるかに小さく、
> 測地線の方位が 0° と 45° に集中していることを示す。**
> **真のユークリッド測地に対する 8 近傍の超過は、この差に FMM 自身の異方性
> （0〜+1.29%）を足した範囲、すなわち概ね +2〜+4% と見積もられる。**

## 5. この測定で確認できていないこと（未確認）

1. **測地線の方位分布そのものは測っていない。**「0° と 45° に寄る」は
   **差の小ささからの逆推定**であり、直接の観測ではない。直接測るなら
   経路を復元して線分ごとの方位ヒストグラムを出す必要がある
2. **私の FMM は 1 次精度**である。2 次精度 FMM や厳密な可視性グラフ法なら
   さらに小さい値になるはずで、**§4 の「+2〜+4%」の上側は私の FMM の誤差に依存する**
3. **5 面しか測っていない。**中央値 +2.2% の面間のばらつき（−0.2〜+2.8%）は
   面数を増やせば広がりうる。**条文に「約」を付けること**
