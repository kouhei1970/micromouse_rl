## 0. なぜやるか

`AUDIT_050` 工程2 は「単一反射の仮定は成り立たない」（`M2` = 0.03015・帯2）と出したが、
これは壁の拡散反射率 ρ = 0.8 を仮定した値である。ρ を変えると帯が変わり、境目は ρ ≈ 0.55
（`AUDIT_050_RESULT` 追記2・`verification/audit_054_reflectance_sweep.py`）。
**ρ は実測していない。**実機で測るには既知の反射率の面が要るが、ユーザは持っていない（2026-08-21）。

ユーザの決定（2026-08-21）:
> 拡散反射率を現在実験で求めるのは不可能です。既知の面がないからです。帯1、帯2 両方行うのが
> 今の正解でしょう。そしてどのくらい結果が違うのか、例えばテスト迷路の中でセンサ位置や角度を
> 変えて二つのシミュレーションで測定した結果を見比べてみたい

すなわち **ρ を推定して一方に賭けるのではなく、単一反射のモデルと相互反射込みのモデルを
両方作り、同じ姿勢で走らせて差の地図を描く。**差が小さければ ρ を決める必要がそもそも無く、
差が大きければ、その場所が ρ の不確かさの効く場所である。

### 比較の対象は生の信号だけ（ユーザの指摘・2026-08-21）

> 壁の有無の判定が覆るかどうかは見なくて良いです。壁のあるなしはアルゴリズム次第という面もあり、
> 比較の対象に加えるのは危険です

**「判定が覆った件数」を主判定量にしない。**閾値の置き方は自分で決められるので、それを混ぜると
物理モデルの差と閾値の差が分離できなくなる。**比較するのは `response()` が返す生の値だけ**である。
この結果、本監査は `classic/sensing.py` の作り直しを待たずに実施できる。

## 1. 比べる 2 つのモデル

| 記号 | 名 | 中身 |
|---|---|---|
| **S** | 単一反射 | 現行の面積分 `mouse/ir_sensor.py::response()`（LED → 面 → PT の 1 回反射のみ） |
| **I** | 相互反射込み | 同じ面積分に、**反射 2 回目以降の寄与を加えた版**（反射 4 回まで） |

- **モデル I は `mouse/ir_sensor.py` の中に実装する**（`response(..., bounces=N)`。既定 `bounces=1`）。
  光線追跡は前向き計算に採用しない（ユーザの決定・2026-08-21・1 姿勢 2.3 秒＝面積分の 40 倍）
- **`bounces=1` は現行の `response()` と数値まで同一でなければならない**（§3 検証0-a）
- 反射 2 回目以降の輸送は**拡散のみ**として扱う（鏡面成分は 1 回目の反射にのみ効かせる）。
  近似の根拠: 鏡面のエネルギー比は 0.10 前後なので、2 回目以降に鏡面を入れても効くのは
  「数%の項のさらに 10%」＝満量比で 10⁻³ 台であり、§5 の分割点（0.01）の 1/10 以下である。
  **この近似の当否は §4 の光線追跡との突き合わせでは検査されない**（光線追跡側も鏡面なし）ので、
  限界として結果に明記する
- 反射回数の数え方は `AUDIT_050` §5 に合わせる（**反射 4 回まで**）。
  反射回数ごとの増分が単調に減衰しないことは既知であり、バグではない
  （面の偶奇。`verification/audit_050_bounce_parity.py`）
- **反射回数ごとの増分を別々に返せること**を実装の要件とする。全ての拡散面が同じ ρ を持つなら
  k 回反射の項は ρ^k に比例するので、**増分を保存しておけば任意の ρ の結果を再計算なしで出せる**

## 2. 標本（格子）と正規化

### 2-1. 満量（正規化の基準）

`AUDIT_050` §2-2 と同じ固定値 **`I_full = 0.8298934`** を使う。本監査の判定量はすべて
この固定値で割った**満量比**で表す。標本の最大値で正規化しない。

### 2-2. 迷路と区画（無作為ではなく、規則で選ぶ）

- 迷路: `competition/mazes/design_turn_v1/maze_41001.npz`（`AUDIT_050` と同じ。
  調整用迷路 seed 41000〜 に属し、確保済みの評価用迷路 1000〜40999 の外）
- 次の 3 つの壁の並びについて、**迷路を左下から行優先で走査して最初に当たった区画**を使う
  （結果を見てから選ばない）:

| 記号 | 壁の並び（機体の向きを北に取ったときの相対） | 状況 |
|---|---|---|
| A | 左あり・右あり・前なし | 直線の通路 |
| B | 左あり・右あり・前あり | 行き止まり |
| C | 左あり・右なし・前なし | 片側だけ壁がある |

### 2-3. 姿勢の格子（無作為ではなく格子。ユーザの指示）

区画中心を原点に、**前後 dx・横 dy・方位 dθ** を格子状に振る:

- `dx ∈ {−40, 0, +40} mm`（3 点）
- `dy ∈ {−40, −30, −20, −10, 0, +10, +20, +30, +40} mm`（9 点。**実走で起きた横ずれ
  17.5〜35.7mm（`exp_030` の実測）を内側に含む**）
- `dθ ∈ {−20, −10, 0, +10, +20} deg`（5 点）
- 1 状況あたり 135 姿勢。センサは **LF/LS/RF/RS の 4 本すべて**を測る
- 機体（シャーシ全幅 60mm）が壁と重なる姿勢は除外し、**除外した件数を報告する**

合計 3 状況 × 135 姿勢 × 4 本 = **1620 点**（モデルごと）。

## 4. 工程1: モデル I の実装を光線追跡で検算する

**モデル I を信用してよいかを先に決める。**`verification/audit_050_raycast.py`（独立に書かれ、
`AUDIT_050` 工程1 で面積分と一致することが確認済み。`M1/σ95` = 1.38）を基準に使う。

- 標本: `AUDIT_050` §2-1 の 200 姿勢（迷路 maze_41001・乱数種 20250821）をそのまま使う
- 光線本数 15,000・乱数種 777001（`AUDIT_050` 追記3 で妥当性を確認済み）
- 反射面は**鏡面なし**（`specular = 0`）。光線追跡に鏡面成分が無いため
- 比べる量は**増分そのもの** `Δ = î(4回まで) − î(1回)`（満量比）

### 4-1. 錨（結果を見る前に測る）

`σΔ` = 同じ 200 姿勢で**乱数種だけを変えた 2 回の光線追跡**の増分の差 `|Δ(種1) − Δ(種2)|` の
95 パーセンタイル。**教授セッションが独立に再計算する**（`RESEARCH_PLAN` §12-9 (b)）。

### 4-2. 主判定量と分割

`M4` = `|Δ_面積分 − Δ_光線追跡|` の 95 パーセンタイル（200 標本・満量比）。

| `M4 / σΔ` | 結論 | 次の行動 |
|---|---|---|
| `≤ 3` | モデル I の実装は光線追跡と一致する | §5 へ進む |
| `3 < ... ≤ 10` | 小さな系統差がある | 差の大きい姿勢を特定し、原因を書いてから §5 へ |
| `> 10` | 実装が食い違っている | **§5 は実施しない。**原因究明に切り替える |

### 4-3. 否定対照（この検査が作動することの実測）

モデル I の**拡散反射率だけを半分（0.8 → 0.4）にした版**で同じ比較にかけ、
**`M4/σΔ > 10` に入ること**を確認する。入らなければ §4 の結論は無効とする。
空振りの側は §4 本体（正しい ρ なら帯1 に入る）が担う。

## 5. 工程2: 格子上で 2 つのモデルの差を測る（本題）

§2-3 の 1620 点で、モデル S とモデル I の生の値を計算し、差の地図を描く。
反射面は**更新後の既定値**（半値角 LED 3.0°・PT 6.0°・鏡面あり）を使う。

### 5-1. 主判定量と分割

`M5` = `|î_I − î_S|` の 95 パーセンタイル（1620 標本・満量比）。**ρ = 0.8 で測る。**

| `M5` | 結論 | 次の行動 |
|---|---|---|
| `≤ 0.01` | **相互反射は要らない。**ρ の不確かさは結果に効かない | モデル S を使い、ρ の議論を閉じる |
| `0.01 < ... ≤ 0.05` | 効く場所がある | 地図で場所を特定し、そこでの扱いを決める |
| `> 0.05` | 大きく効く | モデル I を既定にするか、相互反射を吸収する項を作るかを決める |

分割点 0.01・0.05 の根拠は `AUDIT_050` §5-1 と同一（センサの個体差が数%あるので、
個体差より小さい寄与は実機との照合で区別できない）。**ρ = 0.8 を主判定に選ぶ理由**:
0.8 は現行の既定値であり、もっともらしい範囲の上端である。**上端で効かないなら、
どの ρ でも効かない**と言えるので、ρ の不確かさをこの 1 回で閉じられる。

### 5-2. 副次の報告（判定には使わない）

- `ρ ∈ {0.5, 0.65, 0.8}` それぞれの `M5`（§1 の増分の保存により再計算なしで出せる）
- **差の地図**: 状況 A/B/C × センサ 4 本ごとに、`(dy, dθ)` 平面（dx ごと）で
  `î_I − î_S` を表にする。**符号を落とさない**（相互反射は必ず増やす向きに効くはずだが、
  「〜のはず」で検査を設計しない。実測された符号をそのまま出す）
- 差が最大になった姿勢の一覧（上位 20 点）と、その姿勢の壁の並び
- 相対差 `(î_I − î_S)/î_S` の分布（絶対差が小さくても信号自体が小さい場所では相対差が
  大きくなりうるため。**ただし判定には使わない** — 絶対差が個体差より小さければ
  実機と区別できない、という §5-1 の論理は相対差では成り立たない）

### 5-3. 否定対照（この比較が差を検出できることの実測）

モデル S どうしで、**LED 半値角を 3.0° → 7.0° に変えた版**と本来の版を同じ 1620 点で比べ、
`M5' > 0.05`（＝「大きく効く」の帯）に入ることを確認する。入らなければ §5 の結論は無効とする。

## 6. 予測（教授セッション・結果を見る前）

- `M4/σΔ` は帯1（≤3）に入ると予測する。同じ定式化を 2 通りに実装したものだから
- `M5`（ρ=0.8）は **`0.01 < M5 ≤ 0.05`** に入ると予測する。`AUDIT_050` の `M2` = 0.03015 が
  無作為 200 姿勢での同じ量であり、格子は横ずれの大きい姿勢を無作為標本より多く含むので
  同程度かやや大きいと見る
- 差の地図は**両側に壁がある状況 A・B で大きく、片側だけの C で小さい**と予測する。
  向かい合う面が多いほど 2 回目以降が残るため
- `ρ = 0.5` では `M5 ≤ 0.01`（帯1）に入ると予測する（`audit_054` の走査と整合）

**外れた場合は、外れたことをそのまま書く。**予測は判定に使わない。

## 追記1（2026-08-21）: §4 で使う光学パラメータを固定する。**判定量と分割表は変えない**

**`M4` も `M5` も 1 件も計算していない時点で書く。**本体 §4 は「反射面は鏡面なし」としか
書いておらず、半値角と離隔をどちらの値で走らせるかが決まっていなかったための追記である。

同日（2026-08-21）にモデルの既定値が更新された（`note_034` 追記14・ユーザ承認済み）:
半値角 LED 5.0→**3.0**°・PT 5.0→**6.0**°、離隔 6.5→**6.0**mm、鏡面 0.0→**0.10**、とがり 20→**40**。

### 決めたこと

- **§4（光線追跡との突き合わせ）は、更新後の半値角・離隔で走らせる。**鏡面成分だけを 0 にする
  （光線追跡に鏡面成分が無いため）。理由: §4 が検査するのは §5 で実際に使う実装であり、
  **半値角が狭いほど求積は難しくなる**（3° の LED は 5° より鋭い）。旧半値角で通しても、
  §5 で使う条件での正しさは示せない
- **§4-1 の錨 `σΔ` も、同じ更新後の半値角で測り直す。**`AUDIT_050` の `σ95` は旧半値角
  5°/5° で測った値なので流用しない
- **§5 は更新後の既定値をそのまま使う**（鏡面 0.10・とがり 40 を含む）

**主判定量 `M4`・`M5` の定義と、§4-2・§5-1 の分割表は変えない。**
