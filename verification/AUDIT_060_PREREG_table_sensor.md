## 0. 設計（すべて教授セッションが実測で確かめた事実に基づく）

1. **1 枚の平面からの寄与は 3 つの数で決まる**: 面までの垂直距離 `d`・入射角 `θ`・
   壁に沿った位置 `u`（センサの高さ・取り付け仰角・LED と PT の離隔は機体に固定）
2. 🔴 **表には「累積」を入れる**: `G(d,θ,u)` ＝ 面が `[u, +∞)` に広がっているときの寄与。
   任意の面 `[a,b]` の寄与は **`G(a) − G(b)`**。1 枚の平面では厳密（実測: 正対で 10⁻¹³ 台）
3. 🔴 **遮蔽も同じ引き算で厳密に扱える**。遮る辺はすべて鉛直で、LED と PT は水平位置が同じ
   なので、**影の境目は鉛直な 1 本の線**になる（実測: 999 通りの面×高さすべてで見える範囲は
   1 本の区間、333 面すべてで境目の高さによるずれ 0.000mm）
4. 🔴 **壁は厚み 12mm の直方体なので、長い面 2 枚と妻面 2 枚に分けて、それぞれ同じ表で引く**
   （1 枚の平面として扱うと斜めから見たとき 0.03 ずれる。実測）
5. **幾何は「区画 → そこにある壁」の索引で引く**（迷路 1 枚につき 2ms で構築）。
   光錐が触る壁は中央値 3 個・最大 8 個。まとめて計算すれば 0.127 ms（実測）
6. **隅の相互反射は `AUDIT_059` の実装をそのまま使う**（表にしない。関数が急峻で
   0.5mm で跳ぶため補間できない。実測）

## 1. 作るもの

- `mouse/ir_table.py`（新設）: 表の生成・保存・読み込み・引き算による面の寄与
- `mouse/ir_sensor.py` に `response_table()`（`response_fast()` は変更しない）
- 表の実体は `mouse/data/ir_cumulative_table.npz`（版管理下に置くかは大きさを見て決める）

### 表の刻み（補間の誤差の実測から決めた。**測る前に固定する**）

| 軸 | 範囲 | 刻み | 点数 | 補間の誤差（実測） |
|---|---|---|---|---|
| 距離 `d` | 5〜350mm | **2mm** | 173 | 0.0033 |
| 入射角 `θ` | −85〜+85° | **1°** | 171 | 0.0008 |
| 壁に沿った位置 `u` | **±120mm** | **0.5mm** | 481 | 0.0034 |

`u` の範囲を ±120mm と広く取るのは、**入射角が大きいと壁に沿った光の広がりが伸びる**ため
（±40mm では足りない見込み）。**足りているかは §3 の自己検査3 で確かめる。**

🔴 **表の作り方**: `u` 方向に沿って**1 回の積分で累積する**こと。
`response()` を面ごとに呼んで差を取ってはならない（求積格子が面ごとに変わって恒等式が崩れる。
実測で 0.001 の食い違いが出た）。

## 3. 自己検査（本測定の前に、この順で）

- **自己検査1**: 表の格子点そのものの値が、細かい積分（`n_grid=48` 相当）と満量比 1e-4 以下で一致
- **自己検査2**: 累積の引き算 `G(a) − G(b)` が、1 枚の平面への直接積分と 1e-4 以下で一致
  （距離・入射角・範囲を変えて 30 通り以上）
- **自己検査3**: `u` の範囲が足りている ―― `|u| = 120mm` での累積の残りが満量比 1e-4 以下
  （足りなければ範囲を広げ、**広げたことを報告する**）
- **自己検査4**: 索引で集めた候補が、全走査で得られる近傍を**取りこぼさない**（764 姿勢で 0 件）

## 4. 主判定量と分割

| `M6` = `|response_table − 基準|` の 95 パーセンタイル | 結論 |
|---|---|
| `≤ 0.01` | **合格** |
| `0.01 < ... ≤ 0.03` | 惜しい。差の大きい姿勢の原因を書いて直す |
| `> 0.03` | 不合格。設計に戻る |

| `T` = 1 回あたり | 結論 |
|---|---|
| `≤ 0.5 ms` | **合格**（見積り 0.25ms に対し 2 倍の余裕を見た） |
| `0.5 < ... ≤ 1.0 ms` | 使えるが目標未達。何が支配的かを測って報告する |
| `> 1.0 ms` | 不合格 |

**両方を満たして合格。**あわせて**表の大きさ（MB）と作る時間**を報告する。

## 5. 否定対照（本測定の前に走らせる）

1. **表を粗くする**: 距離 8mm・角度 4°・壁沿い 2mm の表で `M6` を測り、**> 0.03 に入ること**
2. **影の境目を無視する**（面が見えていれば全長を使う）で `M6` を測り、**> 0.03 に入ること**
   （遮蔽を無視すると 68% の姿勢で 0.01 を超えるという実測がある）

**どちらも入らなければ、検査が鈍いということなので §4 の判定を行わない。**

## 追記1（2026-08-22）: 自己検査の判定。**主判定量 `M6`・`T` と分割表は変えない**

第 1 段階（表の生成）の実測を教授セッションが検収した。**`M6` を 1 件も計算していない時点で書く。**

### 🔴 自己検査1・2 のしきい値 1e-4 は、私が基準の分解能より細かく置いていた

実測（自己検査1: 3.32e-4／自己検査2: 1.30e-4）はどちらも登録した 1e-4 を超えた。
しかし**基準そのもの（`response` の格子 48）の揺れを測っていなかった。**教授セッションが測り直した:

| 錨: `response(n_grid=48)` と `response(n_grid=192)` の差（28 通り） | 値 |
|---|---|
| 中央値 | 5.8e-31 |
| **95 パーセンタイル** | **3.78e-4** |
| 最大 | 5.69e-4 |

**基準自身が 95 パーセンタイルで 3.8e-4 揺れている。**しきい値 1e-4 はその内側にあり、
**表の誤差ではなく基準の雑音を測っていた。**実装担当が独立に見つけた事実
（失敗事例で `n_grid` を 48→384 に上げると基準の側が表の値へ寄っていく）とも整合する。

**判定: 自己検査1・2 は合格とみなす。**しきい値を**錨の 95 パーセンタイル ×1.5 ＝ 6e-4** に
改める（結果を見てから緩めた形になるので、**改めた事実と理由をここに残す**）。

> 🔴 **教授セッションの誤りとして記録する。**`AUDIT_057` でも同じことをした
> （`Q` の空振り分布を測らずに分割点を置いた）。**しきい値は、比べる相手自身の
> 揺れを先に測ってから置くこと。**3 度目である。

### 自己検査3（`u` の範囲 ±120mm）は不足しているが、**範囲は広げない**

実測: 入射角 |θ| ≈ 76〜85° の領域（171×173 の格子点のうち 148 点 ＝ 0.5%）で、
±120mm の外側の裾が最大 満量比 **1.4e-3** 残る。**これは実装の誤りではなく、
登録した範囲が極端な斜入射では足りないという物理的な事実である。**

範囲を広げるか判断するため、教授セッションが**実際の姿勢での重みを測った**:

| 実迷路 382 姿勢・寄与のある面 1001 件 | 値 |
|---|---|
| 入射角 76°以上の面 | **10 件（1.00%）** |
| それらが全寄与に占める割合 | **0.049%** |
| そのうち最大の寄与 | 0.0127 |

**判定: 範囲は ±120mm のまま据え置く。**理由 ―― 該当する面は寄与の 0.05% しかなく、
そこでの取りこぼしは最大 1.4e-3 で、**主判定量の分割点 0.01 の 7 分の 1** である。
表を 2 倍（114MB）にする価値はない。**既知の限界として結果に明記する。**

### その他

- **中点則への変更は採用する。**節点（ビンの左端）で評価すると誤差が `O(du)` になり
  満量比 4.2e-3 まで出ていたのを、ビンの中点で評価して `O(du²)` にし 1.9e-5 に縮めた。
  **同じ計算量で 200 倍良くなっており、実装担当の判断が正しい**
- 距離軸は 5〜349mm（刻み 2mm・173 点）になる。事前登録の「5〜350mm」は端数の書き誤り。
  **刻みと点数を正とする**
- 表 `mouse/data/ir_cumulative_table.npz` は **56.9MB** なので**版管理に入れない**。
  生成は 106 秒なので、生成する仕組みだけを版管理に置き、必要なときに作り直す

## 追記2（2026-08-22）: 第 2・3 段階の検収。**主判定量と分割表は変えない**

### 自己検査5（2.857e-3 が しきい値 6e-4 超過）—— **合格とみなす**

🔴 **またしても教授セッションのしきい値の置き方の誤りである。**追記1 で 6e-4 に改めたのは
**「基準そのものの揺れ」**から決めた値だが、**自己検査5 が測っているのは表の補間の誤差**で、
別物である。**補間の誤差は設計の時点で実測してあった**:

| 軸 | 刻み | 補間の誤差（設計時の実測） |
|---|---|---|
| 距離 | 2mm | **0.0033** |
| 入射角 | 1° | 0.0008 |
| 壁に沿った位置 | 0.5mm | 0.0034 |

実測 2.857e-3（距離 20mm で最大・44mm の山の前後に集中）は、**設計時に測って承知のうえで
選んだ刻みが出す誤差そのもの**である。しきい値の側が間違っていた。

> **教訓（3 度目・記録する）**: **しきい値は「その検査が何を測っているか」に合わせて置く。**
> 基準の揺れと、補間の誤差と、実装の誤りは、それぞれ別の量である。

### 自己検査4 の定義変更は妥当

実装担当が「射程内かつバックフェイスカリング」→「LED 光錐 **または** PT 視野」に定義を
変えた（743/764 の取りこぼしが 0 になった）。**これは正しい是正である。**方向を問わない
350mm 半径では、光軸から大きく外れた無関係な矩形まで数えてしまい、検査として意味がない。

### 本測定（教授セッションが姿勢の種類ごとに測り直した）

| 姿勢の種類 | n | `M6` | `T` | 隅を切った `T` |
|---|---|---|---|---|
| **無作為な走行姿勢** | 400 | **0.00301** | **1.399 ms** | 0.638 ms |
| 行き止まりの奥 | 364 | 0.00840 | 2.391 ms | 0.666 ms |
| 登録した標本ぜんぶ | 764 | **0.00504** | **1.870 ms** | 0.647 ms |

**`M6` は合格**（≤0.01。`AUDIT_059` の 0.008322 より 1.7 倍良い）。
**`T` は不合格**（>1.0ms）。ただし `AUDIT_059` の 3.23ms に対し**実際の走行姿勢で 2.3 倍速い**。

🔴 **隅の相互反射が支配的になった。**無作為な走行姿勢で 1.399 − 0.638 ＝ **0.76 ms**（54%）。
隅が「走る」のは 12% の姿勢なのにこれだけかかるのは、**安い判定が 54.7% の姿勢で動く**ため。
教授セッションの見積り（0.12 ms）は**安い判定の費用を数えていなかった**。
