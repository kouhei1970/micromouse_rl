## 0. 設計（すべて教授セッションが実測で確かめた事実に基づく）

1. **1 枚の平面からの寄与は 3 つの数で決まる**: 面までの垂直距離 `d`・入射角 `θ`・
   壁に沿った位置 `u`（センサの高さ・取り付け仰角・LED と PT の離隔は機体に固定）
2. 🔴 **表には「累積」を入れる**: `G(d,θ,u)` ＝ 面が `[u, +∞)` に広がっているときの寄与。
   任意の面 `[a,b]` の寄与は **`G(a) − G(b)`**。1 枚の平面では厳密（実測: 正対で 10⁻¹³ 台）
3. 🔴 **遮蔽も同じ引き算で厳密に扱える**。遮る辺はすべて鉛直で、LED と PT は水平位置が同じ
   なので、**影の境目は鉛直な 1 本の線**になる（実測: 999 通りの面×高さすべてで見える範囲は
   1 本の区間、333 面すべてで境目の高さによるずれ 0.000mm）
4. 🔴 **壁は厚み 12mm の直方体なので、長い面 2 枚と妻面 2 枚に分けて、それぞれ同じ表で引く**
   （1 枚の平面として扱うと斜めから見たとき 0.03 ずれる。実測）
5. **幾何は「区画 → そこにある壁」の索引で引く**（迷路 1 枚につき 2ms で構築）。
   光錐が触る壁は中央値 3 個・最大 8 個。まとめて計算すれば 0.127 ms（実測）
6. **隅の相互反射は `AUDIT_059` の実装をそのまま使う**（表にしない。関数が急峻で
   0.5mm で跳ぶため補間できない。実測）

## 1. 作るもの

- `mouse/ir_table.py`（新設）: 表の生成・保存・読み込み・引き算による面の寄与
- `mouse/ir_sensor.py` に `response_table()`（`response_fast()` は変更しない）
- 表の実体は `mouse/data/ir_cumulative_table.npz`（版管理下に置くかは大きさを見て決める）

### 表の刻み（補間の誤差の実測から決めた。**測る前に固定する**）

| 軸 | 範囲 | 刻み | 点数 | 補間の誤差（実測） |
|---|---|---|---|---|
| 距離 `d` | 5〜350mm | **2mm** | 173 | 0.0033 |
| 入射角 `θ` | −85〜+85° | **1°** | 171 | 0.0008 |
| 壁に沿った位置 `u` | **±120mm** | **0.5mm** | 481 | 0.0034 |

`u` の範囲を ±120mm と広く取るのは、**入射角が大きいと壁に沿った光の広がりが伸びる**ため
（±40mm では足りない見込み）。**足りているかは §3 の自己検査3 で確かめる。**

🔴 **表の作り方**: `u` 方向に沿って**1 回の積分で累積する**こと。
`response()` を面ごとに呼んで差を取ってはならない（求積格子が面ごとに変わって恒等式が崩れる。
実測で 0.001 の食い違いが出た）。

## 3. 自己検査（本測定の前に、この順で）

- **自己検査1**: 表の格子点そのものの値が、細かい積分（`n_grid=48` 相当）と満量比 1e-4 以下で一致
- **自己検査2**: 累積の引き算 `G(a) − G(b)` が、1 枚の平面への直接積分と 1e-4 以下で一致
  （距離・入射角・範囲を変えて 30 通り以上）
- **自己検査3**: `u` の範囲が足りている ―― `|u| = 120mm` での累積の残りが満量比 1e-4 以下
  （足りなければ範囲を広げ、**広げたことを報告する**）
- **自己検査4**: 索引で集めた候補が、全走査で得られる近傍を**取りこぼさない**（764 姿勢で 0 件）

## 4. 主判定量と分割

| `M6` = `|response_table − 基準|` の 95 パーセンタイル | 結論 |
|---|---|
| `≤ 0.01` | **合格** |
| `0.01 < ... ≤ 0.03` | 惜しい。差の大きい姿勢の原因を書いて直す |
| `> 0.03` | 不合格。設計に戻る |

| `T` = 1 回あたり | 結論 |
|---|---|
| `≤ 0.5 ms` | **合格**（見積り 0.25ms に対し 2 倍の余裕を見た） |
| `0.5 < ... ≤ 1.0 ms` | 使えるが目標未達。何が支配的かを測って報告する |
| `> 1.0 ms` | 不合格 |

**両方を満たして合格。**あわせて**表の大きさ（MB）と作る時間**を報告する。

## 5. 否定対照（本測定の前に走らせる）

1. **表を粗くする**: 距離 8mm・角度 4°・壁沿い 2mm の表で `M6` を測り、**> 0.03 に入ること**
2. **影の境目を無視する**（面が見えていれば全長を使う）で `M6` を測り、**> 0.03 に入ること**
   （遮蔽を無視すると 68% の姿勢で 0.01 を超えるという実測がある）

**どちらも入らなければ、検査が鈍いということなので §4 の判定を行わない。**
