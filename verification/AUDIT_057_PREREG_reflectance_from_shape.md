# 監査 057（事前登録）: 実測の距離依存の「形」で、壁の拡散反射率 ρ を縛れるか

- 起票: 教授セッション（2026-08-22）。`AUDIT_056` の途中で気づいた
- **本書は 1 件も測定していない時点で書いている**

---

## 0. なぜやるか

`AUDIT_054`（2026-08-21）は「既存データでは ρ を決められない。ρ は利得と縮退したまま」と
結論した。根拠は **(a)** 実測の場面（壁 1 枚＋床・正対）で多重反射が占める割合が
距離 200mm で 5.3%・50mm で 2.0% と小さいこと、**(b)** ρ を振って当てはめても残差が
ほぼ平ら（ρ=0.3 で 3.09%・ρ=1.0 で 4.15%）だったこと、である。

**この結論は、旧半値角（LED 5°・PT 5°）の下で得られたものである。**当時のモデルは素子の
実際の指向性を外しており、当てはめ残差そのものが 3〜4% あった。2026-08-21 に半値角が
データシートで確定し（LED **3.0°**・PT **6.0°**、`note_034` 追記9・追記14）、
**同じ実測への残差は 0.62%（右センサ・80〜200mm）まで下がった。**

すなわち**雑音の床が 5 倍下がった。**AUDIT_054 が「小さすぎて形に効かない」とした
2〜5% の寄与は、いまや**残差の 3〜8 倍**にあたる。

さらに `AUDIT_056` の測定で、実測の場面での多重反射の割合は距離とともに
**2.1%（44mm）→ 3.6%（84mm）→ 5.4%（150mm）** と動くことが分かった（ρ=0.8）。
**これは倍率の変化ではなく形の変化であり、自由な利得では吸収できない。**

**したがって「ρ は縛れない」を、更新後のモデルの上で測り直す価値がある。**
縛れるなら、ユーザが「既知の反射率の面が無いので不可能」とした量が、
**手持ちの実測だけで決まる**ことになる。

## 1. 方法

反射 k 回の経路は必ず ρ の k 乗を持つので、応答は `S(d, ρ) = Σ_k ρ^k A_k(d)` と分解できる
（`AUDIT_054` と同じ道具立て）。`A_k(d)` は**反射率 1.0** で一度だけ計算しておけば、
任意の ρ を再計算なしで評価できる。

- 配置: `verification/audit_051_measured_vs_model.py` と同じ（正対・壁 1 枚＋床）
- `A_1` は面積分（`mouse/ir_sensor.py::response()`・`n_grid=56`。`AUDIT_056` 工程1' で
  既定の 28 点が強信号を 0.5〜0.7% 低く出すと分かったため、**当てはめの雑音の床を
  下げる側に倒す**）。`A_2..A_4` は光線追跡（`audit_050_raycast.py`・反射回数の差）
- 実測: `mouse/data/ir_measured_front_20260821.csv`（右センサ・当てはめ帯 **80〜200mm**）
- 自由パラメータは `audit_051` と同じく**利得と距離のずれの 2 つだけ**。ρ ごとに
  この 2 つを最適化し直したうえでの残差 `R(ρ)` を比べる（ρ に有利な当てはめを与える）
- ρ の走査範囲: **0.2〜1.0 を 0.05 刻み**

## 2. 主判定量と分割

`Q` = `R_max / R_min`（走査範囲での残差の最大と最小の比）。

| `Q` | 結論 | 次の行動 |
|---|---|---|
| `≤ 1.2` | **データは ρ を区別しない。**AUDIT_054 の結論は更新後のモデルでも変わらない | ρ は未知のまま扱う。`AUDIT_056` の結果に従って進む |
| `1.2 < ... ≤ 2.0` | 弱いが向きはある | 最小の ρ と「最小の 1.1 倍以内に入る ρ の範囲」を報告する。**値は採用しない** |
| `> 2.0` | **データは ρ を縛る** | 最良の ρ とその範囲をモデルの値として採用し、`note_034` と `MODEL_VERIFICATION_PLAN` を改訂する |

分割点の根拠: 残差比 1.2 は、当てはめ帯の残差 0.62% が 0.74% まで悪化することにあたる。
実測の再現性（同じ距離を測り直したときのばらつき）はユーザから聞いていないので、
**利得の個体差（数%）より小さい変化は意味を持たないという `AUDIT_050` §5-1 と同じ考え方**で、
残差が 2 割動くことを「向きがある」の下限に置く。2.0 は残差が倍悪化する水準で、
これだけ動けば当てはめの自由度（利得・ずれの 2 つ）では吸収しきれない。

## 3. 否定対照（検査が作動することの実測。**結果を見る前に走らせる**）

**実測の代わりに、モデル自身が作った合成データを入れて、手順が ρ を取り戻せるかを見る。**

1. `ρ_true = 0.8` で合成した「実測」（距離は実測と同じ点・利得と距離のずれも実測の当てはめ値）に、
   **実測の残差と同じ大きさ（0.62%）の正規雑音**を乗せる
2. 同じ手順で走査し、**`ρ̂` が 0.8 ± 0.1 に入ること**を確かめる
3. `ρ_true = 0.3` でも同じことを確かめる

**両方で取り戻せなければ、§2 の判定は行わない**（手順に ρ を見分ける力が無いということなので、
実測で `Q ≤ 1.2` が出ても「データが平ら」なのか「手順が鈍い」のか区別できない）。

空振りの側は、**ρ に依存しない合成データ**（`A_1` だけで作ったもの）を入れて
`Q ≤ 1.2` になることで確かめる。

## 4. 予測（結果を見る前）

`1.2 < Q ≤ 2.0`（弱いが向きはある）に入ると予測する。理由: 多重反射の割合は当てはめ帯
80〜200mm で 3.6%→5.4% と 1.8 ポイントしか動かず、距離のずれの自由度がその一部を
吸収しうるため。**外れたらそのまま書く。**

## 5. 投入時間の上限と禁止事項

- **測定の合計は 30 分以内。**超える見込みが立った時点で止めて報告する
- 🔴 **合成データの否定対照を先に走らせる。**実測の `Q` を見てから対照を作らない
- 確保済みの評価用迷路（seed 1000〜40999）は使わない
