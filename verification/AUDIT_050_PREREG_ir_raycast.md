## 0. なぜやるか

ユーザとの対話（2026-08-21）で、モデルの正しさに関する問いが 3 つに分かれることを確認した。

| | 問い | 突き合わせるもの | 現況 |
|---|---|---|---|
| A | 実装が定式化どおりか | 独立な 2 通りの数値解法 | **本監査で扱う** |
| B | 近似が直接計算とどれだけ合うか | 表 ↔ 面積分 | 実施済み（`note_034` 追記1〜4） |
| C | 定式化が実機と合うか | モデル ↔ 実測 | 手段が未定義。**本監査では解けない** |

面積分と表は同じ前提から出ているので、B が合っても前提の誤りは出てこない。
一方、光線追跡は**反射を 2 回以上たどれる**。現行の定式化は反射を 1 回しか数えていない
（LED → 壁面 → PT）ので、光線追跡との比較は A に加えて**単一反射という前提の当否**を測れる。
これが実機なしで実行できる検証である。

## 1. 定式化（光線追跡の実装者はこの節だけを仕様とする。`mouse/ir_sensor.py` を読んではならない）

### 1-1. センサ 1 本の構成

LED と PT の対を 1 本のセンサとする。機体座標での取り付け位置 `pos`・光軸 `axis` は
`mouse/params.py` の `RobotParams().sensors`（LF/LS/RF/RS の 4 本）から取る。

- 離隔 `separation_m = 0.0065` m。**縦配置**: LED が上、PT が下。
  機体座標で `led_pos = pos + (0,0,1)*0.00325`、`pt_pos = pos - (0,0,1)*0.00325`。
  取り付け高さ 10mm なので LED は 13.25mm、PT は 6.75mm になる。
- 光軸は LED・PT とも `axis` に平行（アライメント誤差は本監査では 0 とする）。
- 指向性は `cos^m θ`。半値角 5° から `m = ln(0.5)/ln(cos 5°) ≈ 181.76`。LED・PT とも同じ。
- 機体姿勢 `(x, y, θ)` はワールド座標への z 軸まわりの回転と平行移動で与える。

### 1-2. 反射面

壁・柱の足跡（軸平行の長方形）は `classic/geometry.py::wall_obstacles(v_walls, h_walls, cell_size)`
で作る。各長方形は高さ 0〜0.05 m の直方体で、側面 4 枚が反射面になる。
床は z=0 の平面（センサ位置を中心に半幅 0.20 m の範囲だけを持てば足りる）。

反射の性質: 拡散反射率 `diffuse = 0.8`・鏡面成分 `specular = 0.0`（本監査では鏡面は使わない）。
ランバート面とする（反射放射輝度 = 放射照度 × diffuse / π）。

### 1-3. 現行モデルが計算している量（面積分の形）

反射面上の面素 `dA` について、次を全ての面・全ての面素で足し合わせた値が応答である。

```
放射照度   E   = I_led * cos^m(θ_e) / r_e^2          θ_e = LED 光軸と (面素 - LED 位置) のなす角
放射輝度   L   = E * cos(θ_i) * diffuse / π          θ_i = 面の法線と (LED → 面素) のなす角
PT への寄与 dP = L * cos(θ_v) * S_pt * cos^m(θ_r) / r_v^2 * dA
                                                     θ_v = 面の法線と (面素 → PT) のなす角
                                                     θ_r = PT 光軸と (PT → 面素) のなす角
```

`I_led = 1.0`・`S_pt = 1.0`。`r_e` が 0.35 m を超える面素は寄与を 0 とする。
LED から面素、面素から PT のどちらかの線分が他の直方体に遮られる面素は寄与を 0 とする（遮蔽）。

**これが「反射 1 回」の定式化である。**光線追跡はこれと同じ量を、光線を撒く方法で解く。

### 1-4. 光線追跡に求めること

1. LED から出る光線の向きを `cos^m θ` に比例する確率で標本抽出する（重要度標本抽出）。
2. 光線が最初に当たった面で反射させる。**反射 1 回に限る設定**と、**反射を N 回まで追う設定**の
   両方を切り替えられるようにする。
3. PT に入った光の重みを積算し、§1-3 と同じ規格（`I_led = 1.0`・`S_pt = 1.0`）の値にする。
   PT の受光面は点とみなし、PT の指向性 `cos^m(θ_r)` を掛ける。
4. 遮蔽は光線追跡の性質として自然に入る（面まで届かない光線は当たらない）。
5. 面素側から PT を直接結ぶ経路（next event estimation）を使ってよい。使う場合も、
   反射回数の定義は「LED を出てから PT に入るまでに面で反射した回数」とする。

**規格が合っているかは、§3 の検証 0 で先に確かめる**（合わなければ以降の比較は無意味）。

## 2. 標本と正規化

### 2-1. 姿勢の標本

`tests/test_ir_sensor.py::_sample_poses` と同じ手順を使う（再実装してよい）。

- 迷路: `competition/mazes/design_turn_v1/maze_41001.npz`
- 区画を無作為に選び、区画中心から ±40mm ずらし、方位は −π〜π の一様分布
- センサは LF/LS/RF/RS から無作為に 1 本
- **本数 200 姿勢・乱数種 20250821**（予約 seed 帯 1000〜40999 の外。§4 の禁止事項を参照）

### 2-2. 満量（正規化の基準。**姿勢の標本に依存しない固定値**）

`I_full = 0.8298934`（無次元）。

導出: 正対する単一の壁パネル（半長 84mm × 高さ 50mm・厚み 12mm・床なし・遮蔽なし）に対し、
距離 5〜200mm を 0.5mm 刻みで掃引したときの面積分の最大値。ピークは距離 44.0mm。
本監査の全ての判定量は、この固定値で割った**満量比**で表す。

> 標本の最大値で正規化すると標本ごとに基準が動く（`note_034` 追記2 で実際に起きた）。
> 固定値にすることで、乱数種を変えても判定量の意味が変わらないようにする。

## 3. 検証 0（規格合わせ。ここが通らなければ §4・§5 は実施しない）

単純な配置で 2 つの実装が同じ値を返すことを確かめる。

- 配置: §2-2 と同じ単一パネル・床なし・遮蔽なし・正対
- 距離 20 / 44 / 84 / 150 mm の 4 点
- 判定: 満量比の差が 4 点すべてで 0.01 以下

通らない場合、規格（`I_led`・`S_pt`・π の置き場所・立体角の扱い）の取り違えを疑う。
**規格の食い違いは実装の誤りとは別物なので、ここで潰してから先へ進む。**

## 4. 工程 1（A: 実装の検算）— 主判定量と分割

面積分と、**反射 1 回に限った**光線追跡を、§2-1 の 200 姿勢で突き合わせる。

### 4-1. 錨（結果を見る前に測る。光線追跡の統計誤差）

`σ95` = 同じ 200 姿勢を、**乱数種だけを変えた 2 回の光線追跡**で走らせたときの、
満量比の差の絶対値の 95 パーセンタイル。

光線の本数は「`σ95 ≤ 0.005`（満量の 0.5%）かつ 1 姿勢あたり 1 秒以内」を満たす最小の本数を
探して固定する。**両立できない場合は測定を打ち切り、その事実を報告する**（§7 の投入上限）。

### 4-2. 主判定量

`M1` = 満量比の差 `|î_光線追跡 − î_面積分|` の **95 パーセンタイル**（200 標本）。

比 `M1 / σ95` を実数直線として切れ目なく分割する。

| `M1 / σ95` | 結論 | 次の行動 |
|---|---|---|
| `≤ 2` | 実装は定式化どおり | 工程 2 へ進む |
| `2 < ... ≤ 10` | 小さな系統差がある | 差の大きい姿勢を特定し、原因を書いてから工程 2 へ |
| `> 10` | どちらかに実装の誤りがある | **工程 2 は実施しない。**原因究明に切り替える |

### 4-3. 予測（教授セッション・結果を見る前）

`M1 / σ95 ≤ 2` に入ると予測する。ただし遮蔽の扱いが両者で違う（面積分は面素ごとの真偽値、
光線追跡は光線ごと）ため、壁の端や柱の際にあたる少数の姿勢で系統差が出る可能性がある。
その場合は 2〜10 の帯に入ると見る。

## 5. 工程 2（単一反射という前提の検証）— 主判定量と分割

同じ 200 姿勢で、光線追跡の**反射 1 回**と**反射 4 回まで**を突き合わせる。
床の反射を含める（縦配置は PT が床から 6.75mm と近く、ここが効くと見ているため）。

### 5-1. 主判定量

`M2` = 満量比の差 `|î_4回まで − î_1回|` の **95 パーセンタイル**（200 標本）。

| `M2` | 結論 | 次の行動 |
|---|---|---|
| `≤ 0.01` | 単一反射の仮定は使える | 現行の定式化を維持し、壁判定の作り直しへ進む |
| `0.01 < ... ≤ 0.05` | 無視できない | 多重反射を定式化に入れるか係数で吸収するかを起票して判断する |
| `> 0.05` | 現行の定式化は作り直し | センサモデルの作り直しへ戻る |

分割点の根拠: センサの個体差（`gain` のばらつき）は実機で数%あるとユーザから聞いている
（`note_034`「個体差は大きい」）。**個体差より小さい寄与は、モデルに入れても実機との照合で
区別できない**ので、1% を「入れる意味がない」側の境に置く。5% は個体差の上端にあたり、
これを超える寄与は個体差では説明がつかない。

### 5-2. 予測（教授セッション・結果を見る前）

`0.01 < M2 ≤ 0.05` に入ると予測する。理由: 白い拡散面（反射率 0.8）が向かい合う通路では
2 回目の反射が残り、かつ PT が床に近い縦配置では床経由の寄与が効くため。

## 6. 否定対照（検査が作動することの実測）

## 追記（2026-08-21・**判定条件は変えない**。文言の不備の訂正）

**測定を 1 件も走らせていない時点で、実装担当からの指摘を受けて追記する。**
判定量・分割点・予測はいずれも変更していない。変えたのは §1-3 の式の**言葉の説明だけ**である。

§1-3 に `θ_i = 面の法線と (LED → 面素) のなす角` と書いたが、この文言どおりに実装すると
正対する壁でも余弦が負になる。正しくは **`θ_i` = 面の法線と (面素 → LED) のなす角**
（ランバート則で使う入射角）。同じ誤りが `θ_v`（面素 → PT の向きを使う）にもあたるが、
そちらは元の文言で正しい。

実装担当は物理として正しい側で実装しており、既存の面積分の実装も同じ解釈である。
**したがって両実装は同じ量を計算しており、比較は成立する。**

### 教授セッションによる錨の独立な確認（2026-08-21）

同一点に置いた LED・PT が、正対する無限平面を距離 `d` で見るときの応答は、
指数 `m`・拡散反射率 `ρ` に対して閉じた形で書ける（教授セッションが独立に導出）:

```
P = ρ / ((m + 2) d²)
```

導出: `E = cos^m θ · cos²θ / d²`、`L = E·cosθ·ρ/π`、
`dP = L·cosθ·cos^m θ·cos²θ/d² dA`、`dA = 2π d² tanθ sec²θ dθ` より
`P = 2ρ/d² ∫₀^{π/2} cos^{2m+3}θ sinθ dθ = ρ/((m+2)d²)`。

**距離の 2 乗で落ちる**ことに注意（4 乗ではない）。実測の冪則の傾き −1.90 とも整合する。

照合の結果（`d` = 30/50/80/150mm・半値角 5°・`ρ`=0.8）:

| 実装 | 解析解との比 |
|---|---|
| 面積分 `mouse/ir_sensor.py::response()`（`n_grid=200`） | **1.0000**（5 桁一致） |
| 光線追跡 `verification/audit_050_raycast.py`（30 万本・乱数種 7 つ） | **1.00018 ± 0.084%** |

両実装が、どちらとも独立な閉じた形と一致した。**ただしこれは同一点・正対・遮蔽なしの
場合だけである。**§4 の本番（実迷路・離隔あり・斜め入射・遮蔽あり）はこれで代替できない。
