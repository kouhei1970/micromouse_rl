## 0. なぜやるか — **016-G が上げた天井が、016-D の壁を越えるかを測る**

### 0-1. 016-D が測った壁

**016-D（全区画での最短走行に統合）は、凍結された評価用 20 迷路で
20/20 迷路すべて遅くなった**（`card_016d.md` §7-1）:

| | 調整用迷路 20 件 | **確保済みの評価用 20 迷路** |
|---|---|---|
| 改善した迷路 | 0 | **0** |
| 悪化した迷路 | 20 | **20** |
| 対応差の中央値 | +34.3 % | **+35.6 %** |
| (d) 最速タイムの中央値 | — | **15.06 → 20.29 s** |

**機構も特定されている**（同 §7-3・maze_41003 の内訳）:

- **経路長は 16.380 → 13.300 m（−19 %）と、確かに短い**
- **しかし時間の 69.6 % を 0.45 m/s に張り付いて走っている**（対照の平均は 0.806 m/s）
- > **距離の −19 % では、速度の −44 % を埋められない。**

### 0-2. **⚠️ 016-G の利得では、この差は埋まらない見込みである**（**起票時点の見立て**）

**016-D は既に $v_\text{斜め}$ = 0.45 m/s で走っていた。**
**016-G が戻したのも 0.45 m/s である**（対照 0.40 → 016-G 0.45。`card_016g.md` §6-4）。

| 段階 | $v_\text{斜め}^{\max}$ | 備考 |
|---|---|---|
| 016-C（016-D の前提） | 0.45 | **016-D はこの値で走って +35.6 % 負けた** |
| F0 | 0.40 | 速度ループの是正で下がった |
| F0-b | 0.45 | 戻った |
| **cal（安全率 0.75）** | **0.40** | **円弧が速くなったぶん横偏差が増えて下がった** |
| **016-G（45° クロソイド）** | **0.45** | **戻った** |

> **⇒ 斜め区間の速度上限は、016-D の時点から 1 段も上がっていない。**
> **一方で対照（斜めなしの新既定）は cal で −2.54 % 速くなっている。**
> **したがって素直に見れば、差は 016-D の +35.6 % より広がる。**

**⚠️ ただしこれは見立てであって実測ではない。**新既定の積み上げには
**F0（速度ループの是正）・F0-b（参照の弧長内挿）・校正済み安全率 0.75・
45° クロソイド**の 4 つが入っており、**斜め区間以外（直進・円弧・遷移）の走り方は
016-D の時点と違う**。**円弧の速度上限は 0.4965 → 0.5138 m/s へ上がっており、
016-D で「時間の 32.0 % を占めていた円弧」はその恩恵を受ける。**
**どちらがどれだけ効くかは、測らなければ分からない。**

### 0-3. **だから本カードの問いは「勝つか」ではない**

> **問い: 新既定の積み上げを載せたとき、016-D が測った +35.6 % の差は
> どれだけ縮むか。縮まないなら、斜め走行は既定に採らないという裁定の材料になる。**

**「負けました」で終わらせないために、差を区間ごとに分解して報告する**（§5）。

## 2. 実装（**実施時に詰める。起票時点では骨子のみ**）

### 2-1. 何を作るか

**`competition/baseline_slalom_diag.py`（016-D 版）は
F0・F0-b・校正済み安全率 0.75・45° クロソイドのいずれも入っていない。**

**作法 1 に従い、既存ファイルは変更せず、新規ファイルで継承して作る**:

```
SlalomDiagCalPolicy（新規）
  = SlalomDiagPolicy（016-D の斜め経路の選び方）
  + TwoDofControlMixin / ReferenceInterpMixin / VelocityLoopMixin（F0・F0-b）
  + safety_factor = 0.75（校正済み）
  + 参照経路の生成を clothoid_path.build_clothoid_path（L_c = 47.1239 mm・45° のみ）へ差し替え
```

**⚠️ 混ぜ込みの順序は `baseline_slalom_e1t_tr_f0b_cal.py` と同じにする**
（新既定と同じ制御が乗っていることを、継承の連なりで示せる形にする）。

## 4. 予測の事前登録（**実装より前に記入・変更しない**）

> **各予測に ① 量の定義／② 測定条件／③ 閾値 を書く。**
> **さらに作法 7・10 に従い、「上／範囲の中／下」の 3 方向すべてに読みを与える。**

### P1 — **差は縮むが、まだ負けている**

| | 内容 |
|---|---|
| **① 量** | **(d) 最速タイム**の、**同じ迷路どうしの対応差の中央値**（処理 − 対照）÷ 対照 |
| **② 条件** | **調整用迷路（seed 41000〜）の 20 迷路**・§3 の設定・(d) の是正後の評価器 |
| **③ 閾値** | **+15 % 〜 +33 %**（016-D の調整用迷路での +34.3 % より縮むが、まだ正） |

**外れの向き（全域）**:
- **+33 % を超える** = **縮まなかった**。**016-G の利得は全区間では効いていない**。
  §5 の分解で「どこで食われたか」を示して、**斜め走行を採らない裁定の材料にする**
- **0 % 〜 +15 %** = **想定以上に縮んだ**。**残差の所在を分解して次の段階を起票する**
- **0 % 以下（勝った）** = **想定外の勝利**。**必ず内訳と再現性を先に確かめる**
  （**この規模の反転は、まず測定の誤りを疑う**）

### P2 — **完走率は落ちない**

| | 内容 |
|---|---|
| **① 量** | **(a) ゴール到達**が成立した迷路数 |
| **② 条件** | 同上 |
| **③ 閾値** | **20 / 20 迷路**（016-D も 20/20 で、衝突 0） |

**外れの向き**: **19 迷路以下** = **新既定の積み上げが安全側を削った**。
**その場合は P1 の判定より前に原因を突き止める**（速さの話にしない）。

### P3 — **時間の内訳で、斜め区間が最も長く時間を使っている**

| | 内容 |
|---|---|
| **① 量** | 最速走行の**区間ごとの所要時間の割合**（直進／斜め／円弧） |
| **② 条件** | 同上。**016-D §7-3 と同じ分け方**（maze_41003 で内訳を出す） |
| **③ 閾値** | **斜め区間が 30 % 以上**（016-D は 37.6 %） |

**外れの向き**:
- **30 % 未満** = **ボトルネックが斜め区間から移った**。**移った先を名指しして報告する**
- **45 % 超** = **016-D より斜めに時間を食われている**。**クロソイドで接線長が伸びた影響を疑う**
  （45° の遷移は接線長 24.85 → 48.93 mm。**円弧扱いの区間が長くなっている**）

### P4 — **円弧区間は速くなっている**

| | 内容 |
|---|---|
| **① 量** | 円弧区間の**平均速度** |
| **② 条件** | 同上。016-D §7-3 の内訳と同じ量（016-D は **0.451 m/s**） |
| **③ 閾値** | **0.47 m/s 以上**（安全率 0.75 で円弧の上限が 0.4965 → 0.5138 m/s へ上がるため） |

**外れの向き**:
- **0.47 m/s 未満** = **上限が上がっても実速度は付いてきていない**。
  **円弧の速度を決めているのは上限ではない**ということなので、**何が決めているかを測る**
- **0.52 m/s 超** = 上限を超えている。**測定か実装の誤りを疑う**

### P5 — **経路効率 (e′) は 016-D と変わらない**

| | 内容 |
|---|---|
| **① 量** | **(e′) 経路効率**（節点数 ÷ 真の最短歩数。裁定 R14） |
| **② 条件** | 同上。**対照は 016-D の斜めあり**（**斜めなしとは経路が違うので比べる相手が違う**） |
| **③ 閾値** | **同じ迷路どうしの差の中央値が ±0.00**（**経路の選び方は変えていない**） |

**外れの向き**: **±0.00 でない** = **制御の変更が経路の選択に影響した**。
**「1 実験 1 変更」が破れているので、原因を突き止めてから判定する**
（**(e′) は経路の量なので、制御を変えても動かないはずである** —
`card_016cal_switch.md` §7-2-1 で実測済みの性質）。

## 4-1. **外れたらこう読む**

- **P1 が「+33 % 超」** → **斜め走行は既定に採らない**という裁定の材料。
  **ただし「使えない」ではなく「$v_\text{斜め}$ = 0.45 m/s では時間で損」である**
  （016-D §8-1 の言い方を踏襲する）
- **P2 が外れ** → **速さの議論をせず、安全側が削れた原因を先に突き止める**
- **P3・P4 は判定ではなく分解の材料**である。**P1 の結果がどちらでも必ず報告する**
