## 3. 実装の候補（**実測で選ぶ。決め打ちしない**）

| # | 手 | 対象 |
|---|---|---|
| (i) | **車輪 PI のゲイン**（`kp_wheel`=0.05・`ki_wheel`=0.3）の見直し | 行き過ぎの主因が PI なら |
| (ii) | **逆モデル前置補償の係数**（`Ke_eff`・`inv_gain`・摩擦項）の見直し | 前置補償が過大なら定常で行き過ぎる |
| (iii) | **速度指令のレートリミット**（現在は上げ方向のみ $a_\max$） | 下げ方向を制限していないことが効いていれば |

**まず (ii) を疑う**: **直進の定常でも +6% 行き過ぎている**ので、
**過渡ではなく定常の偏り**である可能性が高い。**前置補償が要求より高い電圧を出していれば
定常で行き過ぎる。**（**ただしこれも仮説である。実測で確かめてから直す。**）

## 4. 予測の事前登録（実装前に記入・**変更しない**・§9-16／§9-17）

| # | 予測 | 量と許容差 |
|---|---|---|
| **G1** | **行き過ぎは定常の偏りが主**（過渡の行き過ぎではない） | 量 = 直進の定常区間での（実速度 − 参照）の中央値。**+0.10 m/s 以上なら定常が主**。許容差 ±0.01 |
| **G2** | **是正後、直進の（実 − 参照）が +0.03 m/s 以内**（現状 +0.139） | 量 = 同上の最大値。許容差 ±0.01 |
| **G3** | **是正後、円弧進入時の実測 $a_\text{lat}$ が 5.87 m/s² の内側**（現状 6.08） | 量 = 円弧標本の $v^2\kappa$ の最大。**成立条件**（教授指示） |
| **G4** | **$v_\text{斜め}^{\max}$ が 0.45 から動く**（上がる方に 1 段以上） | 016-C の梯子で再測定。許容差は刻み 0.05 |
| **G5** | **直進の走行タイムは悪化しない**（行き過ぎが消えるぶん遅くなるが 3% 以内） | **⚠️ 行き過ぎは追い風でもあった**ので、**是正すると遅くなる方向に働く**。量 = 対照の (d) との対応差 |

### 4-1. 外れたらこう読む

- **G1 が外れ（定常でない＝過渡が主）** → (i) か (iii) が対象。**(ii) を直しても効かない**
- **G3 が外れ（$a_\text{lat}$ が依然 5.87 超）** → **速度ループだけでは物理の外を消せない。
  F0-b（計画側の余裕）へ進む根拠になる**
- **G5 が外れ（3% 超の悪化）** → **行き過ぎは想像以上に大きな追い風だった。**
  **参照線の解釈に影響する**ので、教授へ報告して扱いを仰ぐ
- **G4 が外れ（梯子が動かない）** → 円弧の物理は改善したが**斜め直線の関門は別の要因**。
  **016-F（操舵ループ）の役割がより大きいことになる**
