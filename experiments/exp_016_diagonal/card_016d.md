## 4. 予測の事前登録（実装前に記入・**変更しない**）

**対照は exp_018 の L0-c+E1T+TR の実測**（同一の帯・同一 20 面）。
比較は**面ごとに対応をとった差**（§9-15）。

| # | 予測 | 量と許容差（§9-16） |
|---|---|---|
| **D1** | **(d) が改善する面は 16 面以上** | 量 = 面ごとの最速タイムの差（処理 − 対照）。**許容差 −0.05 s**（これより小さい改善は「不変」に数える。制御周期 0.01 s の 5 倍） |
| **D2** | **(d) の短縮率の中央値は 15〜30%** | 量 = 面ごとの (対照 − 処理)/対照 の中央値。**016-C の理想 33.03% を下回る**（実走は減速・立ち上がり・追従誤差を含む） |
| **D3** | **参照線が動く**: (d) の中央値が **10.5〜13.0 s** になる | 量 = 処理の (d) の中央値。対照（= M5 gate の基準）は **15.06 s** |
| **D4** | **(a)(b)(c) は不変**（20/20 のまま） | 面ごとの二値。**許容差 0**。McNemar で対応比較 |
| **D5** | **衝突は 0〜2 面** | 016-C は 140 走行で 0 回だが、**統合では未知壁の楽観が絡む**ので幅を持たせる |
| **D6** | **初回最短走行の超過区画が悪化する面が 4 面以上** | §1 のずれ（確定判定は直進基準のまま）による。**exp_015 と同じ機構**。量 = (e') の超過区画 |

### 4-1. 事前に置く「外れたらこう読む」

- **D2 が上振れ（> 30%）** → 実走が理想を超えている。**ありえない**ので、
  **対照の取り違え**（exp_018 の値ではなく別条件と比べていないか）をまず疑う
- **D2 が下振れ（< 15%）** → 減速・立ち上がりの費用が理想の見積もりより大きい。
  **斜め区間の平均長さ（016-A で 2.76 歩）と短縮率の相関**を面ごとに見る
- **D3 が外れて参照線が動かない（> 13.0 s）** → D2 と連動。**同じ原因を見る**
- **D4 が外れて (b) が落ちた** → **持ち時間の圧迫か衝突**。どちらかを
  `note_017` の見方（最終走行の終了時刻）で切り分ける
- **D5 が外れて衝突が 3 面以上** → **未確認の壁へ斜めで突っ込んでいる**。
  §1 のずれが (e) だけでなく安全性に及んだということ。
  **確定判定を斜めモデルへ揃える改修（016-D の範囲外）を次の実験として起票する**
- **D6 が外れて (e') が悪化しない** → **斜めの経路が偶然すべて確定済みの壁の上に
  乗っていた**。E1T が確定させる直進最短経路と斜め経路の重なりを数えて確認する
