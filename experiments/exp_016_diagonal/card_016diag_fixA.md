## 1. 是正の設計（**実施時に詰める。起票時点では骨子のみ**）

### 1-1. 方針 — **新しい印を 1 つ足す。既存の状態は触らない**

**「この迷路でゴールへ到達したことがあるか」を表す印を新設し、
`_use_diag()` だけがそれを見る。**

| 対象 | 扱い |
|---|---|
| **新しい印**（迷路水準） | **`on_maze_start` でだけ偽に戻す。`on_retrieval` では戻さない** |
| `_explored_once`（走行水準） | **1 ビットも触らない** |
| **親の先読み長 `max_cells`** | **触らない**（`_explored_once` を見ている。**触ると 2 変更になる**） |

> **⚠️ `_explored_once` を「迷路水準」に作り替えない。**
> **あれは親の先読み長も決めており、意味を変えると対照（斜めなしの新既定）の
> 挙動まで変わる。**
> **本カードは斜めの分岐の条件だけを直す。**

**⇒ したがって、回収の後も「先読み 2 区画・速度上限 `v_uncertain`」は残る。**
**本カードはそこを直さない**（§4 の限定 2）。

### 1-2. **作法 1 に従い、新規ファイルで継承する**

`competition/baseline_slalom_diag_cal_fixb.py`（是正 (B)）は変更しない。

### A1 — 🔴 **回収の後も印が持続する**（**主判定**・**単独の検証**）

| | 内容 |
|---|---|
| **① 量** | **人工的に `on_retrieval()` を呼んだ直後の、新しい印の値と `_use_diag()` の値** |
| **② 条件** | **判定に使う 20 迷路の【外】**（校正用の 60 迷路 seed 51000〜）で 1 迷路。**ゴール到達後に `on_retrieval()` を 1 回呼ぶ**。対照は**是正 (B) 後**（同じ操作で印が消えること） |
| **③ 閾値** | **是正 (A): 印が真のまま・`target_mode` が `to_goal` なら `_use_diag()` も真**／**是正 (B): 偽になる**（**両方を同じ検査で確かめる**） |

**外れの向き（全域）**:
- **是正 (A) でも偽になる** → **印が別の経路で消されている。**その経路を特定する
- **是正 (B) でも真のまま** → **検査が空振り**（比較になっていない）。検査を作り直す

### A2 — **回収が起きない走行では、是正 (B) 後と挙動が変わらない**（**無害性**）

| | 内容 |
|---|---|
| **① 量** | 走行ごとの記録（結末・タイム・距離・通過区画数）と、**制御周期ごとの左右のモータ電圧の列** |
| **② 条件** | **判定に使う 20 迷路の【外】**（校正用の 60 迷路）で 3 迷路・**回収が 1 度も起きない迷路に限る**。対照は**是正 (B) 後** |
| **③ 閾値** | **全項目・全ティックでビット単位の一致** |

**外れの向き**: **1 ティックでも違う** → **印の追加が、回収の無い場合の挙動を変えている。**
**原因を特定してから進む**（**変えていないはずである**）。

### A3 — **回収が起きた迷路で、斜めが使われ続ける**

| | 内容 |
|---|---|
| **① 量** | **最速走行で斜め経路に乗っていたティックの割合**（`card_016diag_fixB.md` の B2 と同じ数え方。**曲率が 0 かつ参照の方位が 45° の奇数倍**） |
| **② 条件** | **調整用迷路（seed 41000〜）の 20 迷路**・§1 の設定。**対照は是正 (B) 後**。**注目するのは回収が起きた maze_41020・maze_41234** |
| **③ 閾値** | **回収が起きた迷路で、是正 (B) 後より高いこと**（**是正 (B) 後の値は測定済み**） |

**外れの向き（全域）**:
- **変わらない** → **回収の後に斜めが使われない別の理由がある**（**先読み長かもしれない** — §4 の限定 2）
- **下がる** → **印の追加が別のところへ効いている。**帰属が壊れているので原因究明が先

### A4 — **完走率は落ちない**

|---|---|

| **② 条件** | A3 と同じ |
| **③ 閾値** | **20 / 20 迷路** |

**外れの向き**: **19 迷路以下** → **速さの話をせず、原因究明を先にする。**
