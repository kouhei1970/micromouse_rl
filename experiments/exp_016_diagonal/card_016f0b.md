### 2-1. 🔴 **内挿の定義**（教授条件・**実装より前に固定する**）— **$v^2$ を線形内挿する**

**採用**: 参照速度を $v^2$ の線形内挿で読む。

$$s_\text{proj} \;=\; s[i] \;+\; (x - p_x)\cos\psi_i + (y - p_y)\sin\psi_i
\qquad (i = \text{cursor},\; \psi_i = \text{path.heading}[i])$$

$$v_\text{target}(s_\text{proj}) \;=\; \sqrt{\;\max\!\big(0,\;
\operatorname{interp}\big(s_\text{proj};\, s,\, v_\text{plan}^2\big)\big)}$$

**$s_\text{proj}$ は `[s[0], s[-1]]` へ挟む。**
（この沿線方向の射影は、親が横偏差 $e_y$ に使っている座標系の**もう一方の成分**である
—— 親は $e_y = (x-p_x)(-\sin\psi_i) + (y-p_y)\cos\psi_i$ を使っている。**同じ枠組みを使う。**）

**$v$ ではなく $v^2$ を内挿する理由**:
**速度計画は等減速・等加速の区間で $v^2$ が $s$ に対して厳密に線形**である
（`build_speed_profile` の前後 2 パスが $v[i]^2 = v[i\pm1]^2 \pm 2 a_\max\,ds$ を作る）。
**したがって $v^2$ の線形内挿は、その区間で計画の連続形を厳密に再構成する**
（$dv/ds$ も厳密になる）。**超過が生じているのはまさにこの $a_\max$ 律速の区間**なので、
ここが厳密であることが効く。**曲率律速の区間は $\kappa$ が区分定数で $v$ も定数**なので、
$v$ 内挿と $v^2$ 内挿は一致する（どちらでもよい）。

**判定は登録済みの B2（$\lvert dv_\text{cmd}/dt\rvert$ の p99 ≤ 4.3 m/s²）が拾う。**

### 4-2. 🔴 **終端の窓の定義**（裁定 5-1・**D1 の実行より前に固定する**）

**恣意の余地を残さないため、窓を数式で定義してからコミットする**（教授条件①）。

経路点の速度計画 $v_\text{ref}$ が **0 になるのは、`stop_at_end` が終端 1 点を 0 にするときだけ**
である（`build_speed_profile`: $v_\text{ceil}$ は $v_\text{creep}$ で下から押さえた後、
`stop_at_end` のときのみ最終点を 0 にする）。したがって次が一意に決まる:

$$k_\text{end} \;=\; \min\{\,k \;:\; v_\text{ref}[k] = 0\,\}
\qquad(\text{そのような } k \text{ が無ければ } k_\text{end} = \infty)$$

$$W_\text{end} \;=\; \{\,k \;:\; k \geq k_\text{end}\,\}
\qquad\text{（＝「参照が 0 になった最初のティック以降」）}$$

**走行が終端に達しないまま終わった場合**（衝突・打ち切り）は $k_\text{end} = \infty$ となり、
**窓は空**になる。**除外の量は走り方に依存しない**（定義が観測に依存しない）。
