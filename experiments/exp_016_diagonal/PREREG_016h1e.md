## 3. 判定の規則（先に固定する）

### 3-1. 主判定量 $q$ の定義

$$q = \frac{E_{\rm in}^{\rm 凍結}(0.70) - E_{\rm in}^{\rm 凍結}(0.45)}{E_{\rm in}^{\rm 健常}(0.70) - E_{\rm in}^{\rm 健常}(0.45)}$$

- $E_{\rm in}(v)$ = 当該水準の全円弧（20 面連結）の入口 $\lvert e_y\rvert$ の**中央値**[mm]。第 2 段と同一の定義。
- **分母は §1 で独立再計算した健常群の値を使う**（カードの記載値ではない）。
- 分母が $0.20$ mm 未満なら $q$ は定義しない → **K5**（下記 3-4）。

### 3-2. 判定の分割（実数直線を切れ目なく覆う）

| 判定 | 範囲 | 帰結 |
|---|---|---|
| **K1** | $q < 0.25$ | 的中。是正の設計へ進む |
| **K2** | $0.25 \le q < 0.60$ | 部分的。残差の機構の同定を続ける |
| **K3** | $0.60 \le q \le 1.15$ | 外れ。この経路は使われていない → 第四の容疑へ |
| **K4** | $q > 1.15$ | 想定外（凍結で悪化）。模型を捨てて設計へ戻る |

$(-\infty,0.25)\cup[0.25,0.60)\cup[0.60,1.15]\cup(1.15,\infty) = \mathbb{R}$。**穴なし・重なりなし。**

### 3-3. 同値の扱い（境界がちょうど閾値のとき）

- $q = 0.25$ ちょうど → **K2**（K1 は $0.25$ を含まない）
- $q = 0.60$ ちょうど → **K3**（K2 は $0.60$ を含まない）
- $q = 1.15$ ちょうど → **K3**（K3 は上端を含む。K4 は厳密に超過）
- **$q < 0$ は K1 に含まれる。**意味は「凍結すると速度依存が反転した」であり、消失より強い当たりである。
  判定は K1 だが、**判定文にはこの向きを明記する**（「消えた」と「反転した」を同じ語で書かない）。

### 3-4. 主判定量が定義できない場合

$E_{\rm in}^{\rm 健常}(0.70) - E_{\rm in}^{\rm 健常}(0.45) < 0.20$ mm のとき → **K5「上乗せが再現しない」**。
この場合は第 2 段の結果自体が再現していないことになるので、**判定へ進まず、まず再現性を調べる。**

### 3-5. 丸め

$q$ は**小数第 3 位で四捨五入**して判定する（例: $0.2496 \to 0.250 \to$ K2）。
$E_{\rm in}$ は mm 単位で小数第 3 位まで記録する。**丸める前の値も判定文書に残す。**

## 4. 副判定量（判定を左右しない・記述として登録する）

**W1（模型の量的な当否）**: 健常群の実測減衰長 $L(v)$ の 6 点回帰の傾き $a$ [s]。模型値 **1.110 s**、切片 1.807×10⁻¹ m。
$L$ の推定は進入直線ごとに $L_{\rm seg} = \Lambda_{\rm seg} / \ln(\lvert e_y\rvert_{\rm start}/\lvert e_y\rvert_{\rm end})$
（$\Lambda$ は直線の弧長）で出し、水準ごとに中央値を取る。
**$\lvert a - 1.110\rvert \le 0.33$（模型の ±30%）なら「模型は量まで当たっている」と記す。**外れても主判定は動かさない。

**W2（判別力の検査・空振り防止）** 🔴: 低速端 $v=0.45$ で
$\lvert E_{\rm in}^{\rm 凍結}(0.45) - E_{\rm in}^{\rm 健常}(0.45)\rvert / E_{\rm in}^{\rm 健常}(0.45) \le 0.05$。
**構成上ここは一致しなければならない**（$D_0=0.60$ は $v=0.45$ の公称値そのもの）。
**破れたら、凍結サブクラスは分母以外も壊しているので、主判定を出してはならない。**

さらに**発火と空振りの両方を実測してから使う**（§12-9 (c)）:
`tests/test_016h1e_frozen_denominator.py` で、同一の $(e_y, e_\psi, v)$ に対し
(a) $v + v_\epsilon = D_0$ となる $v$ では健常と凍結の $\omega_{\rm ref}$ が**一致する**（空振り側）、
(b) $v = 0.70$ では**一致しない**（発火側）、の 2 つを検査する。**片側だけの検査は認めない。**

## 5. 私（教授セッション）の事前予測 — **判定には使わない**

**この予測が当たったかどうかは判定文書に書くが、判定条文には一切影響させない。**
