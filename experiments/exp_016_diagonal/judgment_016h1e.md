## 判定: **K3 外れ — この経路は使われていない**

$$q = \frac{6.4579 - 0.7775}{5.7614 - 0.6711} = \frac{5.6804}{5.0903} = 1.115934 \;\to\; \boxed{q = 1.116}$$

条文 §3-2 の $0.60 \le q \le 1.15$ に落ちる。**分母を凍結しても上乗せは消えなかった。**
消えないどころか **11.6% 増えた**（凍結の方が速度依存がわずかに強い）。

**⚠️ K4 との境界 1.15 まで 0.034 しかない。**判定は K3 で確定だが、余裕は小さい。
「凍結で悪化（K4）」と読める向きに寄っており、**少なくとも「凍結で改善する」方向の証拠は皆無である。**

## 何が否定されたか

**Stanley 形の横項の速度依存（$1/(v+v_\epsilon)$ の分母）は、進入側の上乗せの機構ではない。**
起票時に見立てを是正して立てた模型 — 「是正は時間で一定だから、速度が上がるほど是正に食う距離が伸び、
固定長の進入直線で消しきれない」— は、**主判定でも副判定でも支持されなかった。**

## 判定に使わないが、次に効く観察

1. **$E_{\rm in}$ は単調でなく、0.60 → 0.65 で跳ぶ**（健常 1.795 → 4.484 mm、2.5 倍）。
   凍結群も同じ位置で跳ぶ（1.544 → 3.723）。**両群に共通する跳びは、分母とは別の何かが
   0.60 と 0.65 の間で切り替わっていることを示す。**これが第四の容疑の最有力の入口である。
2. **$|e_y|_{\rm in} = 0.0000$ の円弧が全面に存在する**（面ごと内訳の min が全面 0）。
   $E_{\rm in}$ の中央値は「典型的な誤差の大きさ」ではなく「誤差ゼロの円弧が何割か」に強く引かれている。
   定義は第 2 段と同一で登録済みのため判定はこのまま出したが、**次のカードでは判定量の選び直しを検討する。**
3. **実測の是正が模型より 6〜7 倍速い**という W1 の事実自体が、追従則の理解が間違っていたことを意味する。
   第四の容疑を立てる前に、**まず「進入直線で $e_y$ は本当に減衰しているのか、それともどこで作られているのか」**を
   直接見るべきである（現在の計装は区間の両端しか持たず、途中の形を持っていない）。
