## 1. なぜやるか — **実測が「入口を直せ」と指し続けている**

### 1-1. 機構の根拠 = **E8**（`card_016f.md` §6-2 (6)・§7）

> **斜め直線区間の横偏差は、そこで作られているのではなく、
> 円弧から持ち込まれて進むにつれ減衰している。**
> 円弧出口からの弧長に対する回帰の**傾き −0.004〜−0.021・相関 −0.50〜−0.77**

**だから 016-F（前方注視 ＋ レートダンピング）は方位 $\psi$ を 28 % 減らしても、
横偏差 $e_y$ は 9 % しか減らせなかった。**016-F の推奨は
**「(B) 採用せず、016-H（遷移域）へ進む」**であり、教授裁定もその形だった。

### 1-2. 余裕の実測値 — **横偏差は運用域を直接食っている**

| 量 | 値 | 出どころ |
|---|---|---|
| 斜め走路の中心線 → 柱の最も近い縁 | **55.154 mm** | 幾何（区画 0.18 m・柱 0.012 m） |

## 2. 変更（**最小の 1 変更**）— **角加速度の前置補償**

### 2-1. 何を足すか

現行の操舵則（`baseline_slalom.py`:1407）:

```
omega_ref = pcurv * v_ref + k_psi * e_psi − atan( k_y * e_y / (|v| + v_eps) )
```

**第 1 項は「いまの曲率に対して定常で必要な角速度」であり、
角速度が変化している最中の分を含まない。**

参照の角速度は $\omega_\text{ref}(s) = \kappa(s)\, v(s)$ なので、その時間微分は

```
dω/dt = v² · (dκ/ds) + κ · v · (dv/ds)
```

**車輪ループは遅れ $t_\text{delay}$ を持つ**（親が既に定義している。`baseline_slalom.py`:848
`t_delay = 2.0 * control_dt`）。遅れを補うには、**いまではなく $t_\text{delay}$ 先の角速度を指令する**:

```
omega_ref' = omega_ref + t_delay · dω/dt
```

**係数は物理から決まる（1.0）。探索しない。**
**これは 016-F0 の $k_\text{acc,ff}$ = 1.0（並進の前置補償）と完全に同型**であり、
**016-F0 は同じ形で並進の行き過ぎを消している。**

### 2-2. 🔴 **なぜ「いま」なら書けるのか — 016-G が前提を作った**

**016-G より前は、直線 → 円弧の曲率が $0 \to 1/R$ とステップで変わっていた。**
**このとき $d\kappa/ds$ は発散するので、上の補償項は書けない**（無限大になる）。

**016-G の 45° クロソイド（$L_c$ = 47.1239 mm）が入ったことで、
$d\kappa/ds$ が有限かつ既知の定数になった。**
**⇒ 本カードの変更は、016-G が成立した後にしか存在しえない。**

**最終形は `clothoid45` を含む**ことをコードで確認済み
（`baseline_slalom_diag_cal_fixd.py`:49 の `name` = `L0-c+DIAG+F0+F0b+cal0.75+clothoid45+alignB+mazeA+guardD`）。

### 2-3. 変更しないもの（**1 実験 1 変更の担保**）

- **既存の方策ファイルは変更しない。**新しい条件は**新規ファイルで継承**して作る（作法 1）
- $k_\psi$・$k_y$・$v_\text{eps}$・円弧半径 $R$・クロソイド長 $L_c$・安全率・$v_\text{斜め}$ は**動かさない**
- **経路は 1 本も変えない**（変えるのは操舵の指令だけ）。**(e′) が全迷路で不変であることを確認に使う**
