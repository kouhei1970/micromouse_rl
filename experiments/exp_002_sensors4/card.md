# exp_002 実験カード: 距離センサ 4 本（正式仕様）での廊下追従

**状態: 事後復元（2026-08-10、学生B が教授承認のもと作成）**
本カードは実験の実施当時に作成されておらず、リポジトリに残った成果物から復元したものである。
復元の限界は §7 に明記する。

- マイルストーン: M1（低レベル運動の直接学習）
- gate: 分岐のない試験コース 20 本 ×5 試行（計 100 試行）を**壁接触なしで完走する率 ≥90%**
- 判定: **未達（79%）**
- Track D 解禁の起算: **本学習 1 本目**（2026-08-10 教授裁定。exp_001 はセンサ 6 本で仕様変更により無効となったため起算に含めない）

---

## 1. 仮説

研究計画書 r6（距離センサを 6 本から 4 本へ戻す裁定）を適用しても、廊下追従の gate は
exp_001（6 本・99%）と同水準で達成できる。実機マイクロマウスの大多数が 4 灯で走行できて
いる以上、4 灯で走れないはずがない、という見立てである。

**反証条件**: 4 本で完走率が明確に落ちれば、この見立ては棄却され、「4 灯で走れる実機は
瞬時値以外の情報（オドメトリ・壁切れ）を併用している」という説明が必要になる。

→ **結果として棄却された**（79%）。この棄却が exp_003（観測への時間情報の追加）の出発点である。

## 2. 変更点（exp_001 からの唯一の変更）

距離センサを 6 本（LF, FL, LS, FR, RF, RS）から **4 本（LF, LS, RF, RS）**へ。
実装はコミット `e041bd8`「refactor(mouse): Apply r6 (4 distance sensors); derive sensor offsets」。

- `mouse/params.py`: 既定センサを 4 本へ。6 本構成は `SENSORS_6` として保存
- 観測次元 13 → **11**（距離 4 ＋ ジャイロ z ＋ 加速度 xy ＋ 車輪角速度 2 ＋ 前ステップ行動 2）
- ポッド geom が 12 → 8 個になる分（−1 g）をシャーシへ戻し、総質量 0.106 kg を維持
- 評価コース XML（`assets/corridor/eval/`）を 4 本構成で再生成

報酬式・ネットワーク構成・PPO ハイパーパラメータ・コース生成規則は exp_001 と同一。

## 4. 結果

### 4-1. gate 判定（seed 3000-3019 × 5 試行 = 100 試行、決定的方策）

| 指標 | exp_002（4 本） | 参考: exp_001（6 本・300 万ステップ） |
|---|---|---|
| **壁接触なし完走率（gate 本体）** | **0.79** | 0.99 |
| 衝突率 | 0.21 | 0.01 |
| 時間切れ率 | 0.00 | 0.00 |
| 平均前進速度（完走試行のみ） | 0.791 m/s | 0.957 m/s |
| 1 区画あたり所要時間（完走試行のみ） | 0.207 s | 0.172 s |
| 行動差分 RMS（完走試行のみ） | 0.577 | 0.949 |
| 符号反転 左 / 右（完走試行のみ） | 31.2 / 17.0 回/s | 34.8 / 51.6 回/s |
| 符号反転 左右平均 | **24.1 回/s** | 43.2 回/s |

**gate 未達（0.79 < 0.90）。** 速度は L0-a（区画ごと停止する超信地旋回走行、1.24 s/区画）
の約 6 倍で、走れているときは十分に速い。

参考として、検証帯（seed 5000-5019 × 1 試行）を 2026-08-10 に事後測定した値は **0.80** で、
gate 帯の 0.79 と一致する。gate 帯に固有の難しさではない。

### 4-2. 学習曲線

**約 16 万ステップで頭打ちし、100 万ステップまで横ばい。**

| ステップ | ep_rew_mean |
|---|---|
| 12,288 | 0.64 |
| 86,016 | 2.34 |
| 159,744 | 4.78 |
| 307,200 | 4.34 |
| 602,112 | 5.04 |
| 970,752 | 4.75 |

**注意（2026-08-10 追記）**: この ep_rew_mean は**学習の進み具合の指標として使えない**。
報酬の整形項は、その場に留まるだけで 1 ステップあたり (1 − γ)·(残り経路長) ≒ 0.005 × 2 m
= +0.010 を生み、時間罰 0.001 を上回る。割引後の収益では最適方策は変わらない（γ が PPO と
一致しているので理論保証は成立している）が、Monitor が出す ep_rew_mean は**割引なしの総和**
なのでエピソード長に強く依存する。実際、完走率 99% の exp_001 と 79% の exp_002 はどちらも
4.7〜5.3 に並び、完走率の差をまったく映していない。exp_003 以降は検証帯の完走率を
学習中に直接記録する（教授承認済み）。

### 4-3. 失敗様式

- **時間切れは 0 件。失敗 21 件はすべて衝突**（壁接触または転倒）。
- **失敗は 20 本中 5 本のコースに集中している**。

| コース | 壁接触なし完走 | 備考 |
|---|---|---|
| 3006 | 0/5 | 全滅 |
| 3013 | 0/5 | 全滅 |
| 3017 | 0/5 | 全滅 |
| 3004 | 1/5 | |
| 3009 | 3/5 | |
| 残り 15 本 | 5/5 | |

方策は決定的で、試行間の違いは初期擾乱（位置 ±0.02 m、方位 ±10°）だけなので、
**100 試行の実効的な独立標本はコース 20 本**である。gate 90% を満たす条件は実質
「全滅するコースを 2 本以下に減らすこと」になる。

失敗した 5 本はいずれも**同方向の連続ターン（2 区画での U 字折り返し）を含む**。
衝突時の到達距離は 1.1〜2.7 m でコース中盤に集中しており、直線での蛇行による
じわじわした失敗ではなく、特定形状での決定的な失敗である。

→ この観察が exp_003 の仮説「4 灯の瞬時値では U 字と行き止まりが区別できない。実機は
オドメトリと壁切れ（センサ値の時間変化）を併用している」につながる。

## 5. 判定

**gate 未達。** ただし「学習が足りない」のではない（16 万ステップで頭打ち、以後 6 倍の
ステップ数を費やしても改善なし）。報酬水準は 6 本版とほぼ同じで完走率だけが落ちており、
**4 灯の瞬時値だけでは廊下追従に必要な情報が足りない**という切り分けになる。

次の実験は exp_003（観測に距離センサの 1 階差分を追加）。

## 6. 記録すべき事故・注記

1. **成果物の上書き（研究計画書 §9-1 の追加根拠となった事故）**: 本実験は exp_001 と同じ
   出力先（`logs/exp_001_corridor/`、`models/exp_001_corridor.zip`、
   `outputs/exp_001_corridor/`）を使ったため、**exp_001 の学習ログと最終モデルを上書きした**。
   exp_001 の学習ログは復元不能。最終モデルは 300 万ステップ時点のチェックポイント
   `logs/exp_001_corridor/rl_model_2999988_steps.zip` のみ残存。
2. **評価コース XML の再生成漏れによる誤測定**: センサを 4 本に変えた直後、コース XML を
   再生成しないまま評価を実行し、完走率 0.00 という結果が出た
   （`outputs/exp_001_corridor/archive/20260810_172018/`）。現在は `CorridorEnv._get_sim` が
   XML の rangefinder 数と仕様の不一致を検出して即座に失敗するようになっている。
3. **exp_001 の学習 seed が gate 帯に侵入した疑い**: 学習コース seed はワーカ 0 で
   2000 から単調に増える規則であり、exp_001 の 300 万ステップ実行（1 ワーカ 50 万ステップ・
   平均エピソード長 約 290）は seed 約 3700 まで到達したと推定される。**gate 帯 3000-3019 が
   学習に混入した可能性が高い**（exp_001 の 99% は汚染の可能性ありとして記録）。
   本実験（exp_002）は 100 万ステップでワーカ 0 が 2689 までしか進んでおらず、**侵入はない**。
   exp_003 以降は `mouse/corridor_env.py` が予約帯（3000-3019、5000-5019）を決定的に
   読み飛ばす（`tests/test_corridor.py` テスト 7 で保証）。
