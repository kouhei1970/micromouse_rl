# exp_004 実験カード: 報酬ポテンシャルへの D₀ オフセット（失敗の記録）

実施: 2026-08-10（学生B）/ 設計: 教授裁定（Φ' = D₀ − D、D₀ = 経路全長）

- マイルストーン: M1（gate は exp_003b で達成済み）。本実験は**報酬設計の根治**が目的
- **判定: 失敗（gate 0.00）。滞留は潰せたが、代わりに衝突が最適解になった**
- 位置づけ: exp_003b からの変更は**報酬のポテンシャルのみ**（観測・PPO ハイパーパラメータ・
  並列環境数 1 はすべて同一）

---

## 1. 仮説

exp_003 で方策が「動かずに時間切れまで粘る」滞留の局所解へ収束した。原因は
Φ = −D（残り経路長の負値）が常に負のため、その場に留まるだけで整形報酬
F = (γ−1)Φ = (1−γ)·D > 0 が毎ステップ入り、時間罰 0.001 を上回っていたこと。

Φ' = D₀ − D（D₀ はそのコースの経路全長、エピソード内で定数）に変えれば Φ' ≥ 0 となり、
滞留時は F = (γ−1)(D₀−D) ≤ 0 で明確に損になる。Φ に定数を加える変換なので
Ng らの定理の保証（最適方策は不変）は保たれる。これで滞留を根治し、
**チェックポイント選択に頼らずに gate を安定して超えられる**はずである。

**反証条件**: 滞留が消えても完走率が改善しなければ、滞留以外の障害がある。

## 2. 変更点（exp_003b からの唯一の変更）

`CorridorEnv(potential_offset=True)`。reset 時に D₀ = `_cum_lengths[-1]`（経路の全長）を
保持し、ポテンシャルを Φ = D₀ − remaining_m とする。既定は False で従来式を再現する。

## 3. 設定

exp_003b と同一（観測 15 次元＝距離 4 ＋ 差分 4 ＋ 7 / PPO / lr 3e-4 / n_steps 2048 /
batch 256 / n_epochs 10 / gamma 0.995 / gae_lambda 0.95 / ent_coef 0.0 /
net_arch [128,128] / PPO seed 0 / **並列環境 1** / 総ステップ 1,000,000）。

## 4. 結果

|---|---|---|---|
| 壁接触なし完走率 | **0.00** | 0.92 | 0.00 |
| 衝突率 | **1.00** | 0.08 | 0.02 |
| 時間切れ率 | **0.00** | 0.00 | 0.98 |

速度 1.403 m/s は exp_003b の 1.46 倍で、**速く走って壁に当たっている**。

している**が、完走率はまったく上がらなかった。

## 5. 原因: 終端状態で Φ ≠ 0 になり「早く終わること」にボーナスが付く

Ng らの定理はエピソード的タスクにおいて**終端状態で Φ = 0** であることを要求する
（終端を吸収状態として扱うため）。そうでないと整形分 γ^T·Φ(s_T) − Φ(s_0) が
「どこで・いつ終わるか」に依存し、最適方策が変わる。

- 現行 Φ = −D: ゴール時 Φ = 0 ✓、衝突時 Φ = −D_T **< 0**。厳密には条件違反だが、
  **たまたま衝突を罰する方向**だったため破綻しなかった
- 本実験 Φ' = D₀ − D: ゴール時 Φ' = D₀ **> 0**、衝突時 Φ' = 走った距離 **> 0**。
  **早く終わるほど γ^T が大きいので、早期終了にボーナスが付く**。衝突は最も早く終わる
  手段なので最適解になる

D₀ = 2.52 m（検証帯の中央値）での割引後の総収益:

| 設定 | ゴール(300 歩) | 1.6 m 進んで衝突(100 歩) | 滞留(時間切れ) |
|---|---|---|---|
| 現行 Φ=−D, t_p=0.001 | 2.587 | 1.884 | 2.320 |
| **本実験 Φ=D₀−D** | 0.627 | **0.890 ← 最適** | −0.200 |
| 現行 Φ=−D, t_p=0.0136 | 0.627 | **0.890** | — |
| Φ=D₀−D ＋ 衝突罰 −1.0 | 0.627 | 0.285 | −0.200 |

**学習は失敗したのではなく、理論どおり正しく最適解へ向かった。** 実測（完走率 0.05 で
横ばい、速度 1.4〜1.7 m/s の「速く走って壁に当たる」方策）は計算と完全に整合する。

### 5-1. 「時間罰を上げる」案も同じ破綻をする

上表の 3 行目のとおり、**Φ オフセット版と時間罰 0.0136 版は数値が完全に一致する**。
Φ に定数 c を足すと F は毎ステップ一律に (γ−1)c だけ変わるので、両者は数学的に等価
であり、**破綻の仕方まで同じ**である。

**時間罰を上げること自体が「早く終わること」に価値を与える**、というのが本質である。
衝突は最も早く終わる手段なので、時間罰を上げるほど衝突が魅力的になる。

### 5-2. 「終端で Φ=0 と強制する」実装をしてはいけない

理論的に正しくするなら終端で Φ = 0 と置くべきだが、そう実装すると最後の遷移で
F = γ·0 − Φ(s_{T−1}) = D_{T−1} > 0 となり、**衝突した瞬間に残り距離ぶんの正の報酬**が
入る（現行 Φ = −D の場合）。これは別の破綻を生む。

## 6. 判定と申し送り

**失敗。** ただし以下は確定した収穫である。

1. **滞留は確実に潰せる**（速度 0.004 → 1.4 m/s）。Φ オフセットの効果自体は設計どおり
2. **滞留と衝突は別々の穴**であり、片方だけ塞ぐと他方に落ちる
3. **現行の報酬に衝突への罰が一切なかった**ことが設計の欠落だった。壁に当たることを
   罰していないのに壁に当たるなというのは無理がある

→ exp_005 は「Φ オフセット ＋ 衝突罰 −1.0」とする。滞留と衝突は構造的に分離不能な
1 つの是正であるため、**1 実験 1 変更の例外**として 2 変更を同時に入れる（教授裁定）。
分離しても両方の失敗が確定している（滞留のみ塞ぐ = 本実験、衝突のみ塞ぐ = 現行 Φ で
衝突罰 −1.0 とすると ゴール 2.587 / 滞留 2.320 / 衝突 1.278 となり滞留が 2 位のまま・
ゴールとの差も現行と同じ 0.267）。
