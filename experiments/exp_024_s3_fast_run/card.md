# exp_024: 最短走行（段階 S3）の完了判定

- 起票: 2026-08-19 教授セッション（単独運用）
- 判定条文は `PREREG.md` を見ること（本カードに条文を写さない。写すと片方だけ直る事故が起きる）

## 仮説

完成した地図から引いた最短経路をターン種別の列として実行し、連続する直進を 1 つの動作に
伸ばして走れば、探索走行より速くゴールに達する。

## 変更点（1 実験 1 変更）

`classic/explorer.py` に最短走行の段階を足した。速度上限は変更していない。
速さの源は「区画ごとの停止・整定を n-1 回分省くこと」だけである。

## 判定量（詳細は `PREREG.md` §6・§7）

- 主: `R = max(最短走行のタイム / 探索走行のタイム)`（対象迷路にわたる最大値）。`R < 1.0` で合格
- 副 1: 最短走行の成立率 `C`
- 副 2: 直線延伸の寄与 `E`（同じ経路を区画ごと停止で走った場合との比の中央値）

## 段階完了の宣言条件

`R < 1.0` かつ `C >= 0.5`（`PREREG.md` §8）。

## 手順

1. 迷路の生成: `competition/maze_gen_turnmix.py` → `competition/mazes/design_turn_v1/`
2. 測定: `experiments/exp_024_s3_fast_run/run_exp024.py`
   （2 条件 × 6 迷路。一次記録は `outputs/exp_024_s3/<condition>/maze_<seed>.json`）
3. 錨の独立再計算: `experiments/exp_024_s3_fast_run/recompute_anchors.py`
4. 判定: `judgment.md` に記す

## 結果

`R = 0.9358`（合格側）／`C = 1/6 = 0.1667`／`E = 0.9358`。
最短走行が成立したのは 6 迷路中 1 迷路（41001）だけ。
直線を伸ばす仕掛けは直進の部分を 10.5% 縮めたが、旋回が最短走行の 41.3% を占めるため
全体では 6.3% にとどまった。詳細は `judgment.md`。

## 判定

**段階 S3 は未完了**（宣言条件 `R < 1.0` かつ `C >= 0.5` のうち後者を満たさない）。

事前登録した予測 2 つを外した。`R` の予測（0.2〜0.6）が外れたのは、
**探索走行と最短走行が同じ経路を走っていた**ためで、その帰結として主判定量 `R` と
副判定量 `E` が同じ数になった。すなわち `note_030` の S3 出口条件「探索より速い」は
判定として機能していない（`judgment.md` §3-1）。

次の仕事は `judgment.md` §5 に記した。要点は **旋回（スラローム）** である。
