## 5. 実装

### 5-1. `mouse/obs_history.py` に `sham` を足す（**既定 False ＝ exp_021 と完全に同一**）

```python
class ObsHistoryWrapper(gym.Wrapper):
    def __init__(self, env, lags=DEFAULT_LAGS, sham=False):
        ...
        self.sham = bool(sham)

    def _stack(self):
        if self.sham:
            # にせ履歴: 遅れの位置に**現在の観測を複製**する（次元は同じ・情報はゼロ）
            return np.concatenate([self._buf[0]] * (1 + len(self.lags))).astype(np.float32)
        return np.concatenate([self._buf[0]] + [self._buf[l] for l in self.lags]).astype(np.float32)
```

- **`sham=False` のとき経路は exp_021 と 1 行も変わらない**（**bit 一致が構成上成立する**）
- **履歴の入れ物（`_buf`）は `sham=True` でも同じように更新する** —
  **更新をやめると `reset`／`step` の計算量が変わり、乱数以外の差が入りうる**。

## 7. 限界（**投入前に明記**）

1. **🔴 本実験は「次元が有害か」を測るのであって、「どの次元数なら無害か」は測らない**。
   **153 次元という 1 点だけである**
2. **P3（ゴール件数）は分離能が弱い**（**exp_019 と exp_021 の差自体が両側 Fisher で p = 0.122**）。
   **単独では判別できない**
3. **P4（正味の前進）は隔たりが 2 目盛しかない**。**単独では判別できない**
4. **「5 区画以上」の閾値は exp_019 の最大到達（5 区画）に由来する**。
   **exp_019 の実測に依存した定義**であり、**別の対照群を使うなら定義し直す必要がある**
5. **6 seed は「迷路の引き」については独立していない**（exp_021 と同じ）。
   **3 群とも同じ迷路の列を走る**ので、**seed 間のばらつきが表すのは方策の初期化と PPO の乱数だけ**
6. **判定は 6 seed の中央値（P1・P4）と 120 走行の件数（P2・P3）である**。
   **n = 6 で判別できるのはほぼ完全に分離する差までである**
7. **🔴 (A) が支持されても「短期文脈は原理的に効かない」ことにはならない**。
   **遅れの組・窓の長さ・与え方はこの 1 通りしか試していない**（exp_021 の限界 2 を引き継ぐ）
8. **符号検定などで棄却できなかったことは「効果が無い」の証拠ではない**
   （**准教授の軌跡追跡の限界の記録を引き継ぐ**。**n が小さいときの棄却失敗は、
   帰無仮説が正しいことを意味しない**）
9. **6×6・検証用の 20 迷路・迷路モード `loop`** の範囲での判定である

## 7-bis. 第 2 弾 B（LSTM）への申し送り

1. **🔴 (C) 汚染の説と同型の設計判断が、LSTM では必ず出る**:
   **「リスポーンのときに隠れ状態をリセットするか」**である。
   - **リセットしない** ＝ **exp_021 と同じ汚染**（**瞬間移動の前後がひと続きの文脈になる**）
   - **リセットする** ＝ **立て直しのたびに文脈を捨てる**（**「立て直したあとどう走るか」の学習が難しくなる**）
   - **どちらを採るかは実験の問いに関わる設計判断**であり、**既定に任せてはならない**
   - **`sb3-contrib` の `RecurrentPPO` はエピソード境界で隠れ状態をリセットするが、
     リスポーンはエピソード境界ではない**（**環境 v2 のリスポーンは走行を続ける**）ので、
     **既定では汚染される側になる**（**未確認。第 2 弾 B の起票時にコードで確かめること**）
2. **(A) と (C) の正面対決の設計案**（**第 2 弾 B の起票で判断する**）:
   **同じ方策構造で「リスポーンで文脈をリセットする群」と「しない群」を比べる**。
   **これは本実験（にせ履歴）では作れない対比**である
3. **観測の次元の手当て**は、**本実験の (B) の判定に従う**
