## 1. 動機 — exp_014 は (e') を直したが、(b) を 1 面壊した

exp_014 で E1 を L0-b へ統合した結果:

- **良くなった**: (e') 1.034 → 1.000、超過区画 0 の面 8/20 → 19/19（悪化 0 面）
- **壊れた**: **maze_7837 で (b) を失った**（$D$=97。帯で最も長い面）。
  E1 が帰路を **+60.4 s** 延ばし、走行 2 の開始が 274.4 → **334.8 s** へずれ、
  **必要 85.9 s に対し残り 85.2 s。0.6 s 足りずに timeout**（exp_014 カード §6-5）

**E1 は「確定するまで探索を続ける」無条件の設計なので、持ち時間と正面から競合する。**
この費用は**計時窓の外（走行の隙間）に落ちるため走行タイムには現れず、持ち時間が
尽きた瞬間に「走行の消失」として全損で現れる**（`note_017`）。

**E2 は、まさにこれを見て打ち切る設計である。**exp_013 で E2 は L0-a の (b) を
80% → 90%（16/20 → 18/20）にした実績がある（決定的だったのは maze_1018・maze_1103 で、
run2 が timeout → goal に変わった）。

## 2. E2 の機構（`competition/baseline_classical_e2.py` の既存設計をそのまま使う）

各計画時に次を評価し、成立したら `target_mode` を `verify` → `to_start` へ切り替える。

$$\text{残り持ち時間} < (D_\text{帰路} + D_\text{最速}) \cdot s_\text{区画} \cdot (1 + \text{余裕})$$

- $D_\text{帰路}$: 既知地図での「現在地 → スタート」の最短**距離**（区画数）
- $D_\text{最速}$: 既知地図での「スタート → ゴール」の最短**距離**（区画数）
- $s_\text{区画}$: **その回で実測した** 1 区画あたりの所要時間 [s/区画]
  （経過時間 ÷ 通過区画数。**ハードコードしない**）
- 余裕: 0.15（既定。`baseline_classical_e2.py` の `DEFAULT_MARGIN`）
- 距離は**悲観地図**（未知壁 = 壁）で測る。悲観で到達不能なら楽観へフォールバック

**E1 と E2 の差は打ち切りの有無だけ**であり、探索の目標の決め方（`explore_targets`）は
同じものを呼ぶ。

### 5-1. V1 の根拠（**紙の上の推定。実測ではない**）

対照（exp_014 の L0-b+E1）の maze_7837 の軌跡から、E2 の打ち切り条件が
**いつ成立するか**を計算した。$s_\text{区画}$ は軌跡から実測どおりに求め、
$D$ は**真の壁**の悲観距離で代用した。

| 量 | 値 |
|---|---|
| $D_\text{最速}$（スタート → ゴール） | **97 区画** |
| 打ち切り成立時刻 $t_\text{cut}$ | **197.9 s**（$s$=0.970 s/区画・$D_\text{帰路}$=102・必要 222.1 s） |
| 帰路の見積 | 99.0 s → **走行 2 の開始 ≈ 296.9 s**（対照の実測は 334.8 s） |
| 走行 2 に使える時間 | **123.1 s**（必要は実測 85.86 s）→ **入る** |

**この推定は「打ち切りが遅い側」に寄せた下界である**: 既知地図の悲観距離は
真の壁の悲観距離**以上**なので、実際の $D_\text{帰路}$ はこれ以上になり、
条件はこれより**早く**成立する。したがって $t_\text{cut} \le 197.9$ s。

**含意（V1 の裏側）**: この面では E2 が**ほぼ即座に**追加探索を打ち切る。
**maze_7837 では E1 の (e') の利得は失われる。**(b) と (e') の交換である。

## 6-1. 量の定義（**裁定 R40 の指示。数え方の規約を先に決めておく**）

### 打ち切り時刻 $t_\text{cut}$ — **「実装が評価した時点」で測る**

**予算の条件は毎ティック評価されるのではなく、計画時（`_do_plan` → `_target_cells`）
にしか評価されない。**したがって打ち切りは**条件が真になった瞬間ではなく、
その後の最初の計画時点**で起きる。

**この 2 つは同じ量の 2 つの数え方であり、値が違う**（R33・R39-3 と同族）:

| 数え方 | 中身 |
|---|---|
| **連続評価**（紙の上） | 条件が最初に真になった時刻。**実装は決してこの時刻では切れない** |
| **離散評価**（実装） | その後の最初の計画時点。**報告と予測はこちらを正とする** |

**設計帯での実測**（maze_41023・余裕 0.50。**発火させるために余裕を上げた診断で、
本実験の条件は既定 0.15 のまま**。測っている量は余裕に依存しない）:

| 量 | 値 |
|---|---|
| 条件が最初に真になった時刻（連続評価） | **106.25 s** |
| 実際の打ち切り（離散評価・`_cut_at`） | **107.50 s** |
| 遅れ | **+1.250 s** |
| その時間帯の区画通過間隔の中央値 | **1.320 s** |

**遅れは計画間隔 1 つぶんに収まっている。**仮説「打ち切りは次の計画時点で起きる」は
**支持**され、対立仮説「$s_\text{区画}$ の数え方が違う」は**棄却**された
（本テストは方策自身の状態をそのまま読むので、数え方の差は生じない）。

**探触子の非侵襲性**: 探触子ありなしで走行の全項目（境界・結果・タイム・経路長・
訪問区画）と最速タイムが**完全一致**することを設計帯 3 面（41003・41135・41023）で
確認済み（教授の条件）。

> **以後の規約**: 下界・上界を事前登録するときは、**どちらの数え方に対する主張かを
> 明記する。**§5-1 の「$t_\text{cut} \le 197.9$ s」は**連続評価に対する下界**であり、
> **離散評価で測る実装の値に対しては下界にならない**（実測 198.19 s で 0.29 s 超過）。
> **この向きの主張は外れとして記録する。**

### この逸脱から残すべきこと

> **事前登録は、登録した本人を「その面を見に行かせる」方向へ引っ張る。**
> 予測を面指定で登録したことで検証の精度は上がったが、**同時に、その面を早く
> 見たいという圧力が生まれ、規律より先に手が動いた。**
> 事前登録の効用と副作用は同じ根から出ている。
