## ② (c) 衝突リスポーン — 衝突で終了せず、開始点へ戻して継続する

**仕様（確定）**:

- 衝突・転倒で **−1.0 を払い、機体を開始点（区画・方位）へ戻す**。**エピソードは継続**する
- **エピソードが終わるのはゴール成立か上限到達のときだけ**
- **訪問済み `_visited` はエピソード単位で維持**（**リスポーン後の再訪問は無報酬**。裁定済み）
  → 「衝突 → リスポーン → 同じ区画で稼ぐ」**報酬ポンプが構成上作れない**
- リスポーン時の擾乱（横 ±20 mm・方位 ±10°）は**reset と同じ規約**にする（要実装判断）

**機構（なぜこれが効くか）**: ポテンシャル整形の恒等式
$\sum_t \gamma^t(\gamma\Phi(s_{t+1})-\Phi(s_t)) = \gamma^T\Phi(s_T)-\Phi(s_0)$ は
**終端の $\Phi$ だけで決まる**ので、開始点へ戻る遷移で $\gamma\Phi(\text{start})-\Phi_c = -\Phi_c$ が
1 度入り、**稼いだ整形をポテンシャル自身が取り返す**。
**報酬契約に一切触れない没収**であり、**走行中の 1 歩ごとの信号は変わらない**
（(a') 没収型が進捗信号を 1/8〜1/10 にした問題は起きない）。

**検算の結果**: 模型で **27/27 通り**（α × 衝突回数 × $D_0$）順序成立。
実走 regime（$T\approx608$ 歩・$\alpha\approx0.133$）でも **(c) は滞留を下回る**（現行・(a') は上回る）。

**意図の条文化（准教授 REVIEW_007 指摘 2 の採用）**:
> **リスポーン下で衝突を抑止するのは時間費用（≈0.131）であって衝突罰（$\gamma^{607}\approx0.048$）ではない。**
> これは**競技の実態（衝突の代価は時間）と学習の経済を一致させる意図された設計**である。
> 時間罰 0.001 の位置づけをこの意図とともに凍結条文に記す。

### 🔴 設計論点 A: **エピソード上限との相互作用**（准教授の未確認③）

**(c) を入れると、ゴール以外のエピソードは必ず上限まで走る。**実測との対比:

| 条件 | 1 本（200 万歩）あたりのエピソード数 | 1 エピソードの平均 |
|---|---|---|
| exp_012 条件 E（現行・衝突で終了） | **12,765** | 157 歩 |
| exp_012 条件 C | 4,924 | 406 歩 |
| exp_012 条件 C' | 8,214 | 243 歩 |
| **(c) 導入後・上限 6000 歩** | **333** | 6000 歩 |
| (c)・上限 3000 歩 | 666 | 3000 歩 |
| (c)・上限 2000 歩 | 1,000 | 2000 歩 |
| (c)・上限 1000 歩 | 2,000 | 1000 歩 |

**🔴 上限 6000 歩のままだと、1 本で触れる迷路が 12,765 → 333 面（38 分の 1）になる。**
迷路は**エピソードごとに新しい seed** なので、**これは迷路の多様性がそのまま 38 分の 1 になる**
ことを意味する。**未知迷路への一般化を課題にしている以上、無視できない副作用である。**

**私の推奨（裁定を仰ぐ）: 上限を 1000〜2000 歩へ短縮する。**

- 根拠: **$\gamma$ = 0.995 の実効地平は 200 歩**である。6000 歩は地平の **30 倍**で、
  **後半はそもそも価値関数から見えていない**。上限 1000 歩（地平の 5 倍）でも
  **見えている範囲はほぼ変わらない**一方、**迷路の多様性は 6 倍**になる
- 副作用: **1 エピソードで許される衝突回数が減る**（衝突の間隔が実測 ≈600 歩なので、
  上限 1000 なら 1〜2 回）。**(c) の「繰り返し衝突を罰する」効果は上限に比例して弱まる**
- **代替案 B**: 上限は 6000 のまま、**衝突 N 回で打ち切り**（ハイブリッド）。
  ただし「打ち切り＝早抜け」が復活するので、**(c) の狙いを部分的に손なう**
- **代替案 C**: 競技の実態に合わせ、**エピソード＝1 面の持ち時間（420 s = 42,000 歩）**とする。
  **競技構造との一致は最も高い**が、**多様性は 47 面/本まで落ちる**ので M2 の学習には過大

**⚠️ この論点は $\gamma$ とも結合している**（地平 200 歩に対して上限をどう置くか）。
**$\gamma$ は変えない**（§2 で棄却済み）ので、**上限側で調整するのが筋**と考える。

### 設計論点 B: リスポーン時の擾乱と決定性

- reset と同じ擾乱を掛けるか、固定姿勢へ戻すか。**擾乱を掛ける方が実機の係員回収に近い**が、
  **決定的評価（同じ seed で同じ軌跡）を保つには乱数の消費順序を固定する必要がある**
- **評価時（`maze6_eval`）は擾乱の有無を学習時と揃える**こと（揃えないと評価が別物になる）
