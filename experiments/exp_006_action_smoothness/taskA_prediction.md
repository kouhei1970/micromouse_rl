## 2. 判別する仮説（教授指示 §2 タスク A の H-A / H-B に、私の第 3 仮説を加える）

| 仮説 | 機構 | 予測される曲線の形 |
|---|---|---|
| **H-A「初期に潰される」** | 罰の符号が一貫しているため、壁回避を学ぶ前に舵の自由度が奪われる | k>0 の 3 本は**最初から立ち上がらない** |
| **H-B「立ち上がってから崩れる」** | いったん走れるようになった後、罰が効いて崩壊する | 一度 0.5 前後まで上がってから落ちる |

**判別基準（先に数値で定義する）**。各条件について `peak = max_t p(t)`、

- **H-A と判定**: k>0 の 3 本すべてで `peak ≤ 0.25`
- **H-B と判定**: k>0 のいずれか 1 本以上で `peak ≥ 0.50` かつ `final ≤ 0.20`
  （＝上がってから落ちた）
- **H-C と判定**: `0.25 < peak < 0.50` かつ `final ≥ peak − 0.15`（落ちずに横ばい）
- どれにも当てはまらない場合は「いずれも不成立」と明記し、形を記述してから解釈する

## 3. 私の事前予測（外れてもよい。外れたら解釈をやり直す）

**主予測: H-A（k>0 の 3 本とも peak ≤ 0.25）。確信度 中（0.6 程度）。**

根拠:

1. 前任者の最終報告では 3 本とも**衝突**で失敗し、完走率が k によらず 0.05〜0.10 に

「罰が実効的な時間罰として効いた」機構（H-B 系）を採る。

**対照 k=0 の予測**: 20〜25 万ステップ付近で一度落ち込む（前任者が exp_003b で観測した

**外れた場合の解釈をあらかじめ決めておく**:

- **H-B が観測されたら**: 罰の形（‖Δa‖² が舵まで罰する）ではなく、罰が実効的な時間罰

  → 案 3 は罰の総量を 1/8 に減らすので有効な公算が大きく、k はタスク B の順序が
  余裕をもって保たれる範囲から選べばよい
- **H-A が観測されたら**: 案 3 でも同じことが起きうる。罰の形を変えるだけでは不足で、

- **H-C が観測されたら**: 走行能力は部分的に残っている＝トレードオフは連続的であり、

## 4. タスク B の先取り（この予測の根拠にした概算。詳細計算は別途 taskB で行う）

γ=0.995・Δt=0.01 s。エピソード長 T ステップの割引後の「実効ステップ数」は
S(T) = (1 − γ^T)/(1 − γ)。毎ステップ一定量 c の罰の割引後総和は c·S(T)。

- ゴール到達: D₀=2.52 m を 0.96 m/s → T ≈ 260 → S ≈ 146
- 途中（半分）で衝突: T ≈ 130 → S ≈ 96
- 差 ΔS ≈ 50

exp_005 のゴール−衝突の余裕は 0.627 − 0.285 = 0.342。順序が崩れる条件は
c·ΔS ≳ 0.342 → **c ≳ 6.8e-3**。‖Δa‖² の実測平均 3.873 を使うと **k ≳ 1.8e-3**。

→ k=1e-2 は順序が崩れる。k=1e-3 は境界付近。**k=1e-4 は余裕で順序が保たれる**（c·ΔS ≈ 0.02）。
それでも完走率 0.05 だったのが「説明できていない崖」であり、これが H-A を主予測にした理由。

### 4-bis-1. 失敗内訳の予測

判別基準を先に数値で定義する。各条件の `cmin = min_t collision_rate(t)`（t ≥ 5 万）。

- **H-A と整合**: k>0 の 3 本すべてで `cmin ≥ 0.60`（衝突率が一度も下がらない
  ＝「壁を避ける」を一度も学べていない）
- **H-B と整合**: k>0 のいずれかで `cmin ≤ 0.40` かつ `collision_rate(100万) ≥ 0.80`
  （下がってから再上昇＝学べたものを失った）

**私の予測: `cmin ≥ 0.60` が 3 本とも成立（H-A 側）。確信度 中（0.6）。**
時間切れ率は 3 本とも全区間で低いまま（`max_t timeout_rate ≤ 0.20`）と予測する。
前任者が「すべて衝突で失敗（時間切れではない）」と最終点で記録しているため、
滞留解へは落ちていない。**もし途中で時間切れ率が高い区間があれば**、
「一度は滞留解に寄ってから衝突解へ移った」ことになり、H-A / H-B のどちらとも異なる
第 4 の経路（滞留 → 衝突）を意味する。その場合は罰が探索そのものを止めた証拠として扱う。

対照 k=0 の予測: 衝突率は初期に高く（≥ 0.7）、単調に近い形で 0.05 前後まで低下する。

### 4-bis-2. 方策標準偏差の予測

**構造的な着眼点（重要）**: 学習初期の方策はガウスで、行動 2 次元・各次元の標準偏差を σ
とすると、探索雑音だけから生じる行動差分は

    E‖a_t − a_(t−1)‖²（雑音由来） = 2 次元 × 2σ² = 4σ²

σ ≈ 0.83 なら 4σ² ≈ 2.76 で、**乱数方策の実測 ‖Δa‖² ≈ 1.52² = 2.31 とほぼ一致する**。
つまり**学習初期の −k‖Δa‖² は、実質的に方策の標準偏差そのものへの罰 −4kσ² である**。
1 ステップあたりの大きさは k=1e-4 で 2.8e-4（時間罰 1e-3 の 0.28 倍）、
k=1e-3 で 2.8e-3（2.8 倍）、k=1e-2 で 2.8e-2（**28 倍**）。

**予測: `train/std` は k で順序づけられて分離する。**
`std(k=1e-2) < std(k=1e-3) < std(k=1e-4) ≈ std(k=0)` が学習の大半の区間で成立する。
定量的には 50 万ステップ時点で `std(k=1e-2) ≤ 0.5 × std(k=0)` と予測する。確信度 中〜高。

**この予測が当たった場合の含意**: k=1e-4 では探索の広さが対照とほぼ同じ**なのに**
完走率が上がらない、という前任者の観測が全区間で確認されることになり、
「探索が止まったから」は **k=1e-4 については棄却**される。崖の説明は別の機構に求める要がある。

**外れた場合（k=1e-2 でも std が対照と同じ）**: 罰が log_std へ届いていない
（＝実装上、罰が方策勾配に効いていない経路がある）疑いが出る。その場合は
`mouse/corridor_env.py` の罰の適用箇所を実装レベルで検証する。

| 登録した予測 | 結果 | 備考 |

**なぜ std の定量予測を外したか**: 「1 ステップあたり −4kσ² の圧力が k 倍で効く」という
見積りは、**エピソード長が k によらず一定**という暗黙の仮定を置いていた。実際には
k=1e-2 のエピソードは 56〜60 歩と対照（248 歩）の 1/4 で、**1 エピソードあたりに受ける
罰の総量が自分で短くなることで頭打ちになる**（自己制限的）。σ への圧力もそこで飽和する。
k=1e-3 は 214〜249 歩と長いので、σ への総圧力は k=1e-2 より大きくなりうる。
逆転はこれで説明がつく。

**なぜ k=1e-3 の時間切れを外したか**: 前任者の「3 本ともすべて衝突で失敗」という記録が
**最終点（100 万）だけ**の観察だったため、それを全区間に外挿してしまった。実際の
k=1e-3 は衝突解と滞留解の間を往復している（時間切れ率 35 万で 0.70、85 万で 0.75、
一方 50 万・65 万では 0.00）。**最終点の失敗様式は途中経過の失敗様式を代表しない。**

### 5-6. この観測が答えたこと・答えなかったこと

**答えたこと 1: 探索の広さでは k=1e-4 の失敗を説明できない（前任者の「未解明」を確定）。**
対照が立ち上がった区間（10 万→25 万）で、std は 0.832→0.695 対 0.817→0.599 と
**2〜14% しか違わない**のに、完走率は 0.95 対 0.05 と 19 倍違う。
なお前任者の「10 万時点で 0.831 対 0.838 とほぼ同じ」は 1 点の一致であり、
**曲線で見ると 10 万以降は一貫して分離している**（100 万で 0.356 対 0.262）。
分離はあるが、**分離の大きさが完走率の差を説明する規模にない**。

**答えたこと 2: k 依存性は「ある」。ただし完走率には現れない。**
完走率は 3 本とも 0.05 で区別がつかないが、これは**完走率が閾値統計**
（ゴールに着けたか否か）であり、3 本ともその閾値の下にあるため飽和しているだけである。
エピソード長（39〜60 / 110〜315 / 110〜249 歩）・std（5 万時点で 0.734 / 0.870 / 0.906）・
失敗様式（純衝突 / 衝突と滞留の往復 / 純衝突）はいずれも **k で明確に順序づけられる**。
機構は連続的であり、二値的な機構（実装上の分岐）を持ち出す必要はない。

**答えなかったこと**: **k=1e-4 が壊れた理由そのもの**。タスク B（§6 の学習勾配）で
示すとおり、k=1e-4 は総収益の順序も学習勾配も対照から 2〜4% しか動かない。
残る候補は「**学習 seed の当たり外れ**」であり、これはタスク C の 2×3 計画
（k=1e-4 × seed 1/2 を追加起動済み）で直接判別する。
