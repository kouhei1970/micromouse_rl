# タスク B: 滑らかさの罰を入れたときの割引後総収益の順序

起草: 学生B 2026-08-11 / 計算スクリプト: `research_notes/scripts/check_return_ordering.py`

`handover/student_b.md` の手順「**新しい報酬項を入れる前に必ず割引後の総収益を代表条件で
計算し、ゴール > 探索 > 滞留 > 衝突 の順序を確かめる**」を、exp_006（`−k‖Δa‖²`）と
案 3（`−k‖a − ā‖²`）について実施する。exp_006 ではこの手順が実施されていなかった。

## 0. 計算モデルと、その検証

報酬（`mouse/corridor_env.py` 438〜448 行、`potential_offset=True`）:

$$r_t = \gamma\Phi(s_t) - \Phi(s_{t-1}) - 0.001 \;[+\,1.0\ \text{(ゴール)}]\;[+\,c_\text{col}\ \text{(衝突)}]\; -\, k\lVert a_t - a_{t-1}\rVert^2$$

$\Phi = D_0 - D$（$D$ は残り経路長 [m]、$D_0$ は経路全長 [m]）。開始時 $D = D_0$ なので $\Phi_0 = 0$。

ポテンシャル項は telescoping するので、$t=1$ から $\gamma^{t-1}$ で割り引いた総収益は

$$G = \gamma^{T}\Phi_T \;-\; (0.001 + c)\,S(T) \;+\; \gamma^{T-1}\cdot(\text{終端ボーナス/罰}),
\qquad S(T) = \frac{1-\gamma^{T}}{1-\gamma}$$

$S(T)$ は**割引後の実効ステップ数**、$c = k\,\mathbb{E}\lVert\Delta a\rVert^2$ は 1 ステップあたりの
滑らかさ罰の平均。**罰は毎ステップほぼ一定量で入るので、実効的に時間罰を増やしているのと同じ**であり、
エピソードが長い条件（＝ゴール到達）ほど多く受ける。

**モデルの検証**（$c=0$ で `experiments/exp_005_collision_penalty/card.md` の既知値を再現できるか）:

| 条件 | 本計算 | card.md | 差 |
|---|---|---|---|
| ゴール（300 歩 ＝ 0.84 m/s） | 0.628 | 0.627 | +0.001 |
| 1.6 m 進んで衝突（100 歩 ＝ 1.6 m/s） | 0.282 | 0.285 | −0.003 |
| 滞留・時間切れ | −0.200 | −0.200 | 0.000 |

→ 一致。以降の計算は exp_004/005 と同じ土俵に乗っている。

## 5. 学習勾配 $dG/dx$ —「もっと進んでから衝突する」は得か

順序（終点どうしの比較）が保たれていても、**そこへ至る途中の勾配**が壊れていれば学習は進まない。
ゴールに一度も到達できない段階の学習は「衝突までの距離 $x$ を伸ばす」ことでしか進まないので、
$dG_\text{collide}/dx > 0$ が要る。

| $x$ [m] | $k$=0 | $k$=1e-4 | $k$=1e-3 | $k$=1.8e-3 | $k$=1e-2 |
|---|---|---|---|---|---|
| 0.2 | 1.117 | 1.095 | 0.889 | 0.707 | **−1.162** |
| 0.6 | 0.882 | 0.862 | 0.681 | 0.520 | **−1.129** |
| 1.0 | 0.686 | 0.669 | 0.509 | 0.367 | **−1.088** |
| 1.6 | 0.455 | 0.440 | 0.308 | 0.190 | **−1.015** |
| 2.0 | 0.334 | 0.321 | 0.205 | 0.101 | **−0.963** |
| 2.4 | 0.236 | 0.224 | 0.121 | 0.030 | **−0.908** |

- **$k$=1e-2: 全区間で負**。「**できるだけ手前で衝突する**」が最適で、進む方向の勾配が反転している。
  観測（エピソード長 39〜60 歩で全区間張り付き＝走り出してすぐ壁）と**完全に整合する**
- **$k$=1e-3: 正だが 2.4 m 付近で 0.030 とほぼ平坦**。余裕 0.079 と併せ、衝突解と滞留解の
  どちらへも転びうる薄氷の状態。観測（時間切れ率が 0.00 と 0.75 の間を往復）と整合する
- **$k$=1e-4: 対照から 2% しか動かない**（1.117 → 1.095）。**報酬の地形では説明がつかない**

## 6. 結論

1. **exp_006 の k=1e-2 と k=1e-3 の失敗は、報酬の地形で説明できる。**前任者の「滑らかさと
   曲がる能力のトレードオフ」ではなく、**罰が実効的な時間罰として働き「早く終わること＝衝突」に
   価値を与えた**ことが直接の原因（`handover/student_b.md` の地雷 3 と同型）。
   前任者はこの検算を実施していなかった
2. **k=1e-4 の崖は報酬の地形では説明できない。**総収益の余裕は 93% 残り、学習勾配は 98% 残る。
   残る候補は**学習 seed の当たり外れ**であり、タスク C の 2×3 計画で判別中
3. **案 3 の $k$**: 順序が崩れる閾値は $k$ = **1.23e-2**（採用仮定）〜3.63e-3（最悪仮定）。
   `design_highpass.md` の第一候補 **$k$ = 2.0e-3 は範囲内**で、採用仮定に対して **6.2 倍**、
   最悪仮定に対しても **1.8 倍**の余裕がある。**衝突罰を深くする必要はない**
4. **案 3 の $k$ の上限**: 余裕を exp_006 の k=1e-3（0.079、薄氷で失敗した水準）より
   十分大きく保つなら、余裕 0.134 を与える **$k$ ≤ 5e-3** を探索の上限に置くのが妥当

## 7. 注意（この計算が保証しないこと）

- 本計算は**代表条件 1 本の決定論的な軌道**を仮定した机上計算であり、方策の分布・
  価値関数の推定誤差・PPO のクリップは含まない。**順序が保たれる = 学習が成功する、ではない**
  （k=1e-4 がその反例）。保証するのは「順序が崩れれば必ず失敗する」という**必要条件**の側だけ
- 罰の平均（3.873 / 0.483）は **exp_005 の学習済み方策**での実測であり、学習初期の
  乱数方策では ‖Δa‖² ≈ 2.31（$4\sigma^2$、$\sigma$≈0.83）と 6 割程度になる。
  初期の罰は上表より小さい
