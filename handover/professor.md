6. **迷路は「データベース置き場」として持つ**（08-23。`note_036`）
7. **確率ロボティクス的な自己位置推定と地図作成を組み合わせる**（08-23）。推定器は拡張

## 注意点
- p 値は条件比較に使えない／**閾値は「対照で空振り分布を測ってから」置く**／コミットは
  `git commit <パス...> -F -`（`git add -A` 禁止。新規は `git add <パス>` を先に）
- 🔴 **一致確認は、変えたものが効く場面を通っていなければ意味がない**（北向き発進しか通さず
  南向きの回帰をすり抜けた実例）／🔴 **コース長の表（`note_035` 追記 7・10）は最短経路とは
  限らない年がある。一致すれば裏付けになるが、一致しないことは誤りの証拠にならない**
- 検収の前に `git status` で、subagent と同じファイルを触っていないか確かめる／
  **Artifact は publish するまで直っていない**（画面を見ずに CSS を直そうとしない）
- **隣接値で結果が反転する。単一の標本で判断しない**（`note_031`）／
  **subagent は「通知を待ちます」でターンを終えると落ちる**／**「〜のはず」で検査を設計しない**
- **同じ向きでも角度の分枝（±π・±2π）が違うと走行が変わる**（`COORDINATE_SYSTEM` §10-3b）
