### `AUDIT_056` の結論: **相互反射は効く。効き方は ρ に依る**

| 条件（`M5` = 2 モデルの差の 95 パーセンタイル・満量比） | 値 | 帯 |
|---|---|---|
| ρ=0.50 ／ 0.65（実迷路の格子 1000 点） | 0.0043 ／ 0.0090 | 帯1 |
| **ρ=0.80** | **0.0181** | **帯2** |
| ρ=0.80・行き止まりの壁へ +10〜+30mm 接近 | **0.0798** | **帯3** |

- 🔴 **境目は ρ ≈ 0.67。`M5` は ρ の 3 乗に比例**（主経路が壁→床→壁→PT の反射 3 回。
  `AUDIT_050` の面の偶奇と独立に一致）
- 🔴 **効くのは姿勢ではなく壁の並び。**行き止まり ≫ 直線通路・片側壁。方位ずれ・横ずれでは
  中央値が 1 割しか動かない。`Δ` は 1000 点すべて正（実測）
- 否定対照は両工程で作動（`M5'`=2.705・工程1' の `M1'/σ95`=2689）
- 🔴 **別件の既知の偏り**: `response()` は既定 `n_grid=28` で**強信号を 0.5〜0.7% 低く出す**
  （半値角が 5°→3° で鋭くなったのに格子点数が 5° 時代のまま）。**作り直した表も同じ偏りを

- p 値は条件比較に使えない／閾値は対照で校正／**検査は作動と空振り両方を実測してから使う**
- コミットは `git commit <パス...> -F -`（`git add -A` 禁止。新規は `git add <パス>` を先に）
- 🔴 **どのパラメータでも隣接値で結果が反転する。単一の標本で判断しない**（`note_031`）
- 🔴 **subagent は「通知を待ちます」と書いてターンを終えると落ちる**（本セッションでも再発）。

  **同じ出力ファイルへ二重に書かせないこと**（実際に同じ工程を二重起動しかけた）
- 🔴 **「〜のはず」で検査を設計しない。**単調減衰も `Δ` の符号も、実測してから書く
