3. **予約 seed の保護を実装で保証**（3000-3019 の gate 用、5000-5019 の検証用）。
   `mouse/corridor_env.py` の `_next_course_seed()` が決定的に読み飛ばす
4. **廊下コースの検証帯 = seed 5000-5019**、gate 帯 = 3000-3019
5. **Track D 解禁の起算**: exp_002 = 1 本目、exp_003 = 2 本目（exp_001 はセンサ 6 本で
   無効なため起算に含めない）
6. **exp_004 は報酬の Φ オフセット**（教授確定待ち。§次にやること）
   - Φ' = D₀ − D（D₀ はそのコースの**経路の全長**。教授裁定で「経路の全長」を採用）
   - 変更は報酬のみ。観測は差分ありのまま据え置き
   - 根拠: 定数の時間罰では滞留報酬 (1−γ)D − t_p が**長いコースほど得**になり、
     t_p = 0.011 では検証・評価帯 40 本のうち 28 本で滞留がまだ得。全滅には 0.020 以上
     必要だが、そこまで上げると短いコース（D₀ = 0.72 m）に過剰。**Φ オフセットは罰が
     コース長に自動追従する**（短いコースで実効 0.0046、長いコースで 0.0208）
   - 注意: Φ オフセットは**時間罰を上げることと数学的に等価**（F' = F + (γ−1)c）。
     「遅い走行が損になる」副作用は両案に共通する。教授の当初の理由づけは訂正済み

## 詰まっている点・注意点

1. **滞留解の罠は未解決**。報酬 r = γΦ(s') − Φ(s) − 0.001、Φ = −(残り経路長 D) は、
   その場に留まるだけで (1−γ)·D = 0.010/step を生み、時間罰 0.001 を上回る。
   残り 2.0 m での割引後の総収益は ゴール 2.067 / 滞留 1.800 / 途中衝突 1.423 で、
   **壁に当たるより留まる方が得**。exp_003b（並列 1）でも 20〜25 万ステップで一度
   完走率 0.00 まで落ち、30 万で自力回復した。並列数によらない構造的な罠
2. **行動振動が実機水準にない**。exp_003b 60 万時点で符号反転 34.8 回/s、行動差分 RMS 1.018
   （exp_002 は 24.1、0.577）。最終モデル（100 万）は 52.3 回/s・RMS 1.528 で**学習前の
   乱数方策と同水準**。100 Hz で 3 ステップに 1 回電圧が反転する方策は実機に持っていけない。
   学習が進むほど振動が増える傾向あり。M1 の gate には含まれないが実機移行の前提
3. **学習を最後まで回すのが最善ではない**。exp_003b は 60 万で検証帯 0.96、100 万で 0.83。
   チェックポイント選択は必ず検証帯で行うこと（§9-7 の手順。test を見て選ばない）
4. **センサノイズがゼロの条件での結果**。1 階差分は実機ではノイズを増幅する（隣接 2 サンプル
   の差はノイズの標準偏差が √2 倍）。ノイズ注入を有効にすると差分の効果が消える可能性あり

## 実行方法（コマンド）

```bash
# 学習（並列 1 が現状の推奨。並列 6 は滞留解に落ちた）
.venv/bin/python experiments/exp_003_sensor_history/train.py --n-envs 1 \
    --log-dir logs/<実験名> --model-out models/<実験名>.zip

# gate 判定（seed 3000-3019 × 5 試行）
.venv/bin/python experiments/exp_003_sensor_history/evaluate.py --model models/<実験名>.zip

# 検証帯での日常判断（seed 5000-5019）
.venv/bin/python experiments/exp_003_sensor_history/evaluate.py --model <...> --split validation

# 単体テスト（24 項目）
.venv/bin/python tests/test_corridor.py
```

学習時間の目安: 100 万ステップで並列 1 が約 34 分、並列 6 が約 26 分（いずれも検証帯の
定期評価 20 回ぶん 90 秒を含む）。**バックグラウンド実行**すること（10 分の前景タイムアウトを
超えるため）。
