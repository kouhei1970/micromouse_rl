# 日本語技術文書の用語・慣用表現辞書

制定: 2026-08-10（ユーザー指示）。本プロジェクトの**すべての日本語文章**（チャット報告・研究ノート・計画書・コミットメッセージ・スライド）に適用する。

**目的**: 英語からの直訳で生じる「日本の技術者が普段使わない日本語」を排除する。
**範囲**: ユーザーの専門は**制御・航空宇宙・機械**。この 3 分野の定訳・慣用句は使ってよい。**それ以外の分野（IT・医学・経済等）の専門語・慣用句は使わず、日常語に開く**（やむを得ず使う場合は一言解説を添える。〜/.claude/CLAUDE.md の解説ルールに従う）。

---

## 1. 直訳禁止語 → 自然な工学日本語

英語に引きずられた語。左の表現を見つけたら右に置き換える。

| 直訳（使わない） | 元の英語 | 日本の技術者の言い方 |
|---|---|---|
| 憲章（プロジェクト文書の） | charter | **研究計画書**（`docs/RESEARCH_PLAN.md` の呼称）、本計画、基本方針、実施要領。※「憲章」は国連憲章のような公的文書の語であり、研究プロジェクトの方針文書には使わない（2026-08-10 ユーザ指摘） |
| 崩壊した（性能・挙動が） | collapse | 破綻した、限界を超えた、成り立たなくなった |
| 汚染された値・データ汚染 | contaminated | 当てにならない値、異常値が混入した、外れ値まじりの |
| 病的な（値・条件が） | pathological | 定義上破綻する、極端な、意味をなさない |
| 走行包絡・性能包絡 | envelope | 性能範囲、運用領域、（航空では）飛行領域 |
| 参照値・参照信号 | reference | 目標値、指令値、基準値 |
| 攻撃的な（制御・走行） | aggressive | 思い切った、応答の速い、強気の |
| 頑強な・堅牢な（制御が） | robust | ロバストな（制御分野の定訳）、（統計では）頑健な |
| 正気度確認 | sanity check | 検算、妥当性の簡易確認 |
| 素朴な実装・ナイーブな | naive | 単純な、工夫のない、そのままの |
| バニラの | vanilla | 素の、標準のままの |
| 些末でない・非自明な（乱用） | non-trivial | 一筋縄でいかない、手間のかかる（数学の「非自明」は可） |
| 封筒の裏の計算 | back-of-envelope | 概算、ざっくり見積り |
| 教師-学生モデル | teacher-student | 教師-生徒モデル（機械学習の定訳。※本プロジェクトのセッション役割名「教授/学生」は固有名としてそのまま） |
| 切除実験 | ablation | アブレーション（要素抜き比較実験）、要素抜き実験 |
| パラレルアクシス合成 | parallel axis | 平行軸の定理（による合成） |
| ボアサイト | boresight | （センサ・光学系の）光軸 |
| レンジファインダ | rangefinder | 距離センサ、測距センサ |
| プラギング | plugging | 逆転制動（プラギング、と併記は可） |
| ストールトルク | stall torque | 停動トルク（モータ定格。maxon 等の国内カタログ準拠。誘導機の試験は「拘束」） |
| アーティファクト（計測の） | artifact | 計測系に起因する見かけの現象、偽の信号 |
| グラウンドトゥルース | ground truth | 真値 |
| コンタミ以外の文脈の「クリーンな」 | clean | 素性のよい、混入のない |
| 隔離する（問題を） | isolate | 切り分ける |
| 免罪する（部位を） | exonerate | 無実と確認する、原因から除外する |
| 迅速な反復 | rapid iteration | 試行の回転が速い、短い周期で回す |
| てこ入れする・レバレッジする | leverage | 活用する |
| 目的関数を最適化する文脈以外の「最適な」乱用 | optimal | 適切な、ちょうどよい（真に最適性を主張する時のみ「最適」） |

## 2. 分野別の定訳（そのまま使ってよい語）

### 制御
定訳: 目標値・指令値／偏差／整定時間／立ち上がり時間／行き過ぎ量（オーバーシュート）／定常偏差／時定数／一次遅れ・二次遅れ／むだ時間（ひらがな）／不感帯／飽和／ハンチング／チャタリング／リミットサイクル／積分器ワインドアップ・アンチワインドアップ／極・零点／固有値／位相余裕・ゲイン余裕・安定余裕／帯域／遮断周波数／開ループ・閉ループ／フィードフォワード／外乱／外乱抑圧／オブザーバ（状態観測器）／カルマンフィルタ／同定（システム同定）／ロバスト制御／ゲインスケジューリング／定値制御／追従制御

### 機械・車両
定訳: 慣性モーメント／慣性乗積／重心／剛性／減衰／固有振動数／共振／振動モード／静定・不静定／自由度／拘束（力学）／転がり抵抗／クーロン摩擦・粘性摩擦／静止摩擦（スティクション）／バックラッシ／予圧（軸受）／公差／輪荷重・接地荷重／荷重移動／摩擦円／スリップ・横滑り／グリップ／トレッド（輪距）／ホイールベース（軸距）／超信地旋回・信地旋回／据え切り／（タイヤの）引きずり／惰行／回生ブレーキ・逆転制動／停動トルク／無負荷回転数／逆起電力／減速比／整流子・ブラシ／コアレスモータ／バンプストッパ（突き当て）

### 航空宇宙
定訳: 姿勢・姿勢制御／機体座標系・慣性座標系／迎角／横滑り角／失速／きりもみ／滑空／フレア／トリム（釣り合い）／舵面（エルロン・エレベータ・ラダー＝補助翼・昇降舵・方向舵）／推力／比推力／ジンバル・ジンバルロック／慣性計測装置（IMU）／推測航法／テレメトリ／地上局／与圧（機体の。※軸受は「予圧」）／機能縮退／フェールセーフ／冗長性／耐故障性

### マイクロマウス競技（本プロジェクトの中心分野・競技者の用語を使う）

2026-08-10 ユーザ（競技に通じた立場）から教示された標準用語。**英語からの直訳や独自の言い換えをせず、この語を使うこと**。

| 用語 | 意味 | 誤用・直訳（使わない） |
|---|---|---|
| **マウサー** | マイクロマウス競技者の通称 | 「競技参加者」等の説明的言い換えは不要 |
| **超信地旋回** | その場で左右輪を逆方向に回して機体中心まわりに回る旋回（戦車の用語に由来。片輪を止めて回るのは「信地旋回」）。曲がるたびに停止するため、これを使う走行方式は下記の 2 通りに分かれる | ×stop-and-turn、×その場旋回（意味は同じだが競技では超信地旋回と呼ぶ） |
| **超信地旋回走行（区画ごと停止）** | 1 区画進むごとに停止し、向きを変えるときも停止して超信地旋回する。**最も基本的・低速**。本プロジェクトの L0 はこれ | ×stop-and-go（教授セッションが英語から持ち込んだ誤用） |
| **超信地旋回走行（直進連続）** | **直進できる区間は止まらずに走り続け**、曲がるところでのみ停止して超信地旋回する。実機の探索走行で広く使われる標準的な方式（2026-08-10 ユーザ教示） | — |
| **スラローム走行** | 曲がるところでも停止せず、曲線を描いて走り続ける走行方式。最短走行で用いられる。超信地旋回を使う 2 方式と明確に区別される | ×連続走行（「直進連続」と紛らわしい）、×ノンストップ走行 |
| **斜め走行** | 区画の対角（45°）方向に走る上級技法。最短走行の高速化に用いる | ×ダイアゴナル走行 |
| **探索走行** | 迷路の壁情報を集める走行（通常 1 走目） | ×サーチ走行 |
| **最短走行** | 得た地図から最短経路を選んで走る走行（通常 2 走目以降） | ×高速走行（速さではなく経路が最短であることを指す語） |
| **区画** | 迷路を構成する 18 cm 角のます目 | ×セル（コード内の識別子は cell で可、文章では区画） |
| **柱** | 区画の四隅にある 1.2 cm 角の支柱（格子点） | ×ポスト |
| **壁切れ** | 走行中にセンサが壁の途切れ目を検出すること。位置補正に用いる | — |

※本プロジェクトの L0 ベースラインは「**区画ごとに停止する超信地旋回走行**」であり、マウサーの走行方式の中で最も基本的・低速な部類にあたる（研究計画書 §7 参照）。

### 計測・実験
定訳: 校正（計量法・JIS の正式。防衛・航空系慣用の「較正」も可、文書内で統一）／真値／系統誤差・偶然誤差／外れ値／残差／許容誤差／分解能／量子化／折り返し（エイリアシング）／ナイキスト周波数／ローパスフィルタ／ゼロ位相フィルタ／サンプリング周波数／ドリフト／オフセット／再現性／トレーサビリティ／受け入れ試験／慣らし運転／エージング（通電慣らし）／実機検証／検証と妥当性確認（V&V）

### 強化学習・機械学習（本プロジェクトで頻出。**必ず一言解説を添えて使う**）
定訳: 方策（policy。×政策）／報酬／観測／状態／行動／エピソード／探索と活用／カリキュラム学習／模倣学習／蒸留／教師-生徒／特権情報／報酬整形（シェーピング）／疎な報酬／サンプル効率／方策勾配／過学習／汎化／推論／チェックポイント／ドメインランダム化／アブレーション

## 3. 同音・多義語の使い分け（間違えやすい）

| 英語 | 使い分け |
|---|---|
| stall | 航空=**失速**／モータ定格=**停動**（トルク）／誘導機試験=**拘束** |
| constraint | 力学=**拘束**（拘束力・拘束条件）／最適化=**制約**（制約条件） |
| tracking | 制御=**追従**（追従制御）／レーダ・目標=**追尾**／日常=追跡 |
| trajectory / path | 宇宙・弾道=**軌道**／描いた跡=**軌跡**／計画する道筋=**経路**（経路計画） |
| calibration | 計量法・JIS=**校正**／防衛・航空系慣用=**較正**（文書内で統一） |
| preload / pressurization | 軸受・ばね=**予圧**（初期荷重）／機体・キャビン=**与圧** |
| tolerance | 寸法=**公差**／計測・判定=**許容誤差**・許容値 |
| regression | 統計=**回帰**／ソフトウェアの機能後退=**退行**（グローバル CLAUDE.md の必須ルール） |
| damping / attenuation | 振動・制御=**減衰**／信号の減り=**減衰**だが増幅の逆は「利得低下」とも |
| identification | システム同定=**同定**／個体の判別=**識別** |
| frame | 座標の話=**座標系**（機体座標系・慣性座標系）。「フレーム」は構造部材か動画のコマ |
| nominal | 仕様書の値=**公称**（公称値）／定格の話=**定格** |

## 4. 表記の約束

- **カタカナ語尾の長音**: 機械・制御系の慣例に従い 3 音以上は省略で統一 — モータ、センサ、ダンパ、フィルタ、キャスタ、コントローラ、オブザーバ、スラスタ。（コンピュータ、ユーザも同様）
- **ひらがな表記が定着**: むだ時間、ばね（機械要素のとき）、ねじ
- **単位・記号**: 数式・記号には意味と単位を併記（グローバル CLAUDE.md のルール）。数式の表記形式（ターミナル=プレーンテキスト／.md=LaTeX）も同 CLAUDE.md に従う
- **「〜性」の乱造をしない**: ×追従性が悪い→○追従が遅い・偏差が大きい、×応答性→○応答（が速い/遅い）は文脈で判断（「速応性」「即応性」は定訳なので可）

## 5. 他分野・IT 俗語 → 日常語

ユーザーは IT 分野の専門家ではないため、IT 俗語・慣用句は日常語へ開く（技術用語として必要なら一言解説つきで使う）。

| 避ける | 言い換え |
|---|---|
| エッジケース・コーナーケース | 極端な条件、めったに起きない条件 |
| スモークテスト | ざっと動作確認 |
| ドライラン | 予行、実行せずに手順確認 |
| ボイラープレート | 定型コード、お決まりの部分 |
| デグレ（った） | 退行（既存機能が壊れた） |
| イテレーション | 反復、繰り返し（の 1 周） |
| ローンチ | 開始、公開（ロケットは「打ち上げ」） |
| フィックスする | 修正する、直す |
| ペンディング | 保留 |
| アサイン | 割り当て、担当にする |
